# Style Fusion · 動效設計風格混合器

做動效設計時的「風格參考台」：選圖像風格、選動效風格，可以隨意混搭，即時看到混合後的動畫，並拿到可直接使用的色板、緩動曲線、代碼與 AI 提示詞。

純網頁，不需要打包成 exe。

## 快速開始

**Windows 一鍵啟動**：雙擊 `start.bat`。第一次會自動安裝套件，需要時自動建置，然後在瀏覽器開啟（網址 http://127.0.0.1:4173）。沒有安裝 Node.js 但已有建置好的 `dist/index.html` 時，會直接用瀏覽器開啟成品。要改程式的話雙擊 `start-dev.bat`（開發模式，存檔即更新）。關閉黑色視窗就會結束。

手動啟動：需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的網址（預設 http://localhost:5199）。

要得到一個可以直接雙擊開啟的單一檔案：

```bash
npm run build
```

成品是 `dist/index.html`（內含全部程式、樣式、Three.js 與音訊引擎，不需要伺服器）。雙擊即可在瀏覽器開啟，也可以丟到任何靜態主機。字體來自 Google Fonts，離線時會退回系統字體，功能不受影響。

## 怎麼混合

- 圖像風格與動效風格各可同時選最多 6 個，每個有 5%–150% 的強度。
- 數值類參數（描邊粗細、擠壓幅度、抖動量…）依強度加權平均。
- 類別類參數（填色模式、背景、字體…）由「主風格」決定；點皇冠圖示可以換主風格。
- 後期特效依固定順序串接，同種特效合併參數。
- 緩動曲線以函數層級混合，再反推最接近的 `cubic-bezier` 與 CSS `linear()`。
- 色板有三種策略：交錯（預設）、只用主風格、OKLab 融合。

「搭配度」是依分類親和度與人工標記的搭配關係估算的參考值，不是對錯判斷；反差大的組合常常正是靈感所在。

## 3D

「3D 渲染」分類的 25 種風格都是真的 3D：Three.js 即時算出光影、材質與輪廓，再交給 2D 畫筆與 WebGL2 後期特效一起處理，所以 3D 風格可以和其他任何風格混搭（例如「黏土 3D × 像素化後期」）。

- **材質**：白模、啞光、黏土、卡通、塑膠、鉻、黃金、玻璃、珍珠、全息、X 光、線框、霓虹、紙雕、1-bit 抖動…
- **燈光**：攝影棚、陽光、柔光、戲劇、霓虹、無光照；**面數**：平滑或低多邊形。
- **3D 運鏡**：環繞、推拉變焦、穿梭飛行、升降鏡頭、翻滾、爆炸分解、翻轉、漂浮、橫移。
- **場景**：島嶼（體素）、幾何群、角色、立體文字、無縫循環的地形。
- Three.js 只在第一次用到 3D 時才載入；上百張縮圖共用同一個渲染器（主舞台一個、縮圖一個），不會吃光瀏覽器的 WebGL 內容數。

## 聲音

右側「聲音」分頁（快捷鍵 **M** 開關）。音樂依你選的風格自動作曲，並**與動畫的循環長度對齊**：音樂的長度是動畫循環的整數倍，節拍脈動的動效會改用音樂的 BPM，所以畫面與音樂是同一個節奏。

- 作曲：依圖像風格決定曲風與調式、動效風格調整速度與能量；同一組設定每次都得到同一首歌，按「重新作曲」換一個旋律。
- 六種聲音方案演奏同一首歌，可以逐一試聽（按 ▶ 循環播放，再按一次暫停；試聽中換曲風、調性、速度，聲音會自動換成新的歌）：
  - **8-bit NES**：兩條脈衝波、三角波低音、噪音鼓，和弦以快速琶音模擬。
  - **Game Boy**：脈衝波與 4-bit 波形表。
  - **C64 SID**：PWM、鋸齒波與會掃動的低通濾波器。
  - **Mega Drive FM**：調頻合成的貝斯、銅管與電鋼琴。
  - **MIDI（真實樂器）**：依 General MIDI 音色編號，用真實錄音的取樣樂器演奏（鋼琴、吉他、弦樂、銅管、木管、電鋼琴、打擊樂…）；沒有取樣的音色（合成器、人聲）才用程式合成。
  - **XM 追蹤器**：把同一批取樣轉成 16 位元、多音區的 XM 樂器，再用音軌與追蹤器效果（琶音、顫音、延遲）演奏。
- 動畫音效：主體在動畫中經過起跳、落地、彈出等瞬間時自動觸發；拖曳時間軸、暫停、慢放都會即時跟上。
- 導出：**WAV**（音樂＋音效混音，或可無縫循環的純音樂）、**標準 MIDI**（.mid）、**XM 模組**（.xm，可用 OpenMPT 等追蹤器開啟）；導出 MP4 時可以把音樂與音效一起封裝成 AAC 音軌。
- 瀏覽器規定要先有一次點擊才能出聲，所以每次開啟頁面聲音預設是關的。

## 功能

- **混合器**：風格庫 + 即時舞台 + 風格處方。縮圖有三種模式：單獨示範、套在目前主體上、預覽「加入目前混合」後的樣子。
- **舞台工具**：播放／逐幀、時間軸、0.25×–1× 慢放、洋蔥皮、運動軌跡與間距、四宮格同看四種主體、畫面比例切換、存下目前畫面。
- **風格處方**：色板（點擊複製）、緩動曲線圖、時長與錯峰建議、動作參數、渲染與後期鏈、設計要點、推薦搭配。
- **微調**：速度、循環長度、幀率、隨機種子、線條粗細、後期強度、色板策略、自訂色板。
- **代碼**：CSS（`linear()` 精確緩動 + 關鍵影格）、GSAP（CustomEase）、After Effects 表達式、JSON。
- **AI 提示詞**：依目前組合產生圖像與影片提示詞（中英各一）與反向提示詞。
- **起點選擇**：第一次開啟（或按混合配方旁的「換個起點」）可以從 12 個不同主題的完整案例挑一個：復古遊戲、經典卡通、3D 黏土、3D 金屬文字、東方水墨、合成波、紙雕童話、設計海報…
- **導出**：GIF、MP4（H.264＋AAC 音訊，需要支援 WebCodecs 的瀏覽器）、WebM、PNG 序列（ZIP）、精靈圖、單張 PNG；可選透明背景。導出是逐幀離線渲染，幀與幀之間的時間精確，不受電腦快慢影響。
- **收藏與分享**：收藏存在瀏覽器；配方碼（`SF1.` 開頭的字串）可貼給別人還原整組設定。
- 淺色／深色／跟隨系統；尊重系統的「減少動態效果」設定（預設暫停，點播放即可）。

## 專案結構

```
src/
  engine/          渲染引擎
    brush.ts         風格化畫筆：所有主體都透過它繪圖，風格因此自動套用到每個形狀
    motion.ts        時間管線：幀率步進、停格、往返、慢放、衝擊停頓
    resolve.ts       風格混合器（權重、類別勝出、後期合併）
    easing.ts        緩動庫、函數級混合、cubic-bezier 擬合、CSS linear() 取樣
    postfx/          WebGL2 管線與 40 個著色器
    subjects/        14 個主體
    three/           3D 舞台：材質、燈光、5 個場景
    loop.ts          動畫循環長度（動畫與音樂對齊用）
  audio/           聲音系統
    compose.ts       作曲（和弦進行、旋律、貝斯、琶音、鼓）→ 抽象歌曲資料
    chip.ts gm.ts xm.ts    各聲音方案的演奏／合成
    midi.ts xm.ts    MIDI 與 XM 檔案編碼
    sfx.ts           5 個音效包
    plan.ts          風格 → 曲風／方案／音效包，並與動畫循環對齊
    engine.ts        Web Audio 播放、時間軸同步、音效觸發
  data/            風格資料（visual.ts、visual3d.ts、motion.ts、motion3d.ts、recipes.ts）
  lib/             風格處方、代碼與提示詞產生、導出
  store/           Zustand 狀態、配方碼
  components/      介面
```

## 新增一個風格

圖像風格寫在 `src/data/visual.ts`，只需要宣告讓它成立的關鍵參數：

```ts
V({
  id: 'my-style',
  name: '我的風格',
  en: 'My Style',
  cat: 'modern',
  desc: '一句話描述。',
  tips: ['要點一', '要點二'],
  kw: 'english keywords for AI prompts',
  pairs: ['ui-micro'],          // 推薦搭配的動效風格 id
  look: {
    pal: { bg: '#fff', p: '#f55', s: '#55f' /* …其餘角色可省略 */ },
    fill: 'cel',                // 填色模式
    stroke: 2,                  // 描邊粗細
    post: [{ fx: 'halftone', cell: 1 / 80 }],   // 後期特效
  },
}),
```

動效風格寫在 `src/data/motion.ts`：

```ts
M({
  id: 'my-motion',
  name: '我的動效',
  en: 'My Motion',
  cat: 'ui',
  desc: '一句話描述。',
  tips: ['要點'],
  kw: 'english keywords',
  dur: '200–400ms',
  ae: '// After Effects 表達式（可省略）',
  move: { ease: 'quart', squash: 0.3, over: 0.2, fps: 12, jitter: 0.4 },
}),
```

存檔後縮圖會自動出現並即時渲染。可用的填色模式、後期特效與動作參數，見 `src/engine/types.ts` 與 `src/engine/fx.ts`。

## 開發用指令

```bash
npm run typecheck                 # 型別檢查
npm run test:audio                # 音訊自我檢查（循環對齊、作曲、MIDI／XM 編碼、音效）
npx tsx scripts/audio-render.ts 曲風 方案 [秒數] [種子] [輸出資料夾]   # 例：… pop midi 3.2 11 out，在 Node 裡渲染成 WAV
npm run audio:sweep [方案] [動畫秒數]   # 所有曲風各渲染一次，檢查數值與耗時
npm run samples:build             # 重新下載並建置取樣包（需要網路與 ffmpeg）
npx tsx scripts/stems.ts 曲風 輸出資料夾   # 每一軌單獨渲染，配合 python scripts/levels.py 看混音平衡
npx tsx scripts/loop-check.ts     # 檢查持續音樂器的循環接縫有沒有「啪」聲
```

## 已知限制

- MP4 導出需要瀏覽器支援 WebCodecs（Chrome、Edge 最穩，較新的 Safari 與 Firefox 也已支援）。不支援時，導出視窗會把 MP4 標成不可用，請改用 WebM 或 GIF。
- `dist/index.html` 約 9 MB（含取樣），本機開啟沒問題；放到網站上第一次載入會比較久。
- 取樣來源的授權：CC0 的素材沒有限制；Freesound、Karoryfer 的樂器商用前請先看 `CREDITS.md`。
- 音樂是依規則作曲的，目的是給「配樂方向」與節奏參考，不等於專業配樂。聲音方案是模擬各種音源的音色與限制（例如 NES 的四個聲道），不是逐位元複製真機。
- `.xm` 檔的速度只能是整數 BPM，所以長度可能和動畫有 0.5% 內的差異。
- 風格示例是用程式「詮釋」風格，目的是給方向，不等於該風格的最終成品。
- 在 claude.ai 這類沙盒嵌入框裡，瀏覽器可能擋下自動下載；請在本地版本導出。
