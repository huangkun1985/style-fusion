# 驗收清單：2.0 α1～α3（給你照著點）

用 **`start.bat`** 開（這樣才連得上你的 Claude）。每一項：怎麼做 → 應該看到什麼。有不對的，回報「第幾項、看到什麼」就好；能截圖最好。
我沒看過完整的畫面、聽不到聲音，所以下面標 ★ 的是我最沒把握、最需要你看的。

## A. 第一次打開（舊資料）
1. 打開 → 右下角提示「已把舊版的資料轉成專案…，N 個收藏變成「我的配方」（原資料保留）」。頂列左邊是「我的第一個專案」，旁邊綠點「已儲存」。
2. 頂列專案名稱 ▾ → 「我的配方」：以前的收藏都在。
3. ★ 整體觀感：預設是「簡潔模式」——頂列、舞台、一條播放列、場景帶、右邊 Agent。你覺得夠清爽嗎？哪裡還太擠？

## B. 簡潔／進階
4. 頂列「簡潔｜進階」切到進階 → 左邊出現素材庫、舞台下面出現「混合配方」、右邊多「調整／聲音／規格」頁籤。切回簡潔。頂列的按鈕位置不該動。
5. ★ 圖像風格的標記從青色改成中性灰（介面只剩琥珀一個顏色）。好不好認？

## C. 復原、重做、A／B
6. 按「重抽」兩次 → Ctrl+Z 兩次 → 回到最開始；Ctrl+Shift+Z 再前進。
7. 進階模式拖一個微調滑桿 → Ctrl+Z 一次就整段退回（不是一格一格）。
8. 頂列「記下 A」→ 重抽 → 按住「按住看 A」：舞台變回 A；放開回到現在。

## D. 存檔
9. 專案名稱 ▾ → 改名 → 存成檔案（下載 `.sfproj`）→ 新專案 → 專案名稱 ▾ → 開啟檔案（選剛剛那個）：全部回來。
10. 關掉瀏覽器再開：還是同一個專案。

## E. Agent（需要 start.bat）
11. 右邊 Agent 面板上面寫「已連上你的 Claude」。（如果寫「手動模式」或「沒登入」，告訴我。）
12. ① 風格模板「換一個」→ 選一個 → ② 把主題那一行改成你要的內容 → ③ 生成 → 等 40～70 秒（面板上有秒數、可以取消，舞台照常可以用）。
13. ★ 結果出現在舞台上、還沒套用：舞台下緣有一行說明；按住「比較」看原本的；「套用」或「放棄」。**生成的東西好不好看？** 這是最需要你判斷的。
14. 套用之後，播到不滿意的地方 → 播放列「附上時間點」（或輸入框旁的「附上」）→ 輸入要改什麼 → Enter。約 10～20 秒後出現修改卡：摘要、動到的時間（可以點，點了跳過去）、每幀耗時。
15. ★ 連續改三次，每次都改在你指的地方嗎？有沒有改到你沒說的東西？
16. 選到內建模板（例如「文字標誌」）時：面板說「不能用對話修改」，但可以直接改標題、副標（打完字離開輸入框，Ctrl+Z 一次退回整段）。

## F. 風格牆
17. 播放列「風格」→ 舞台變成 3×3，同一段內容 9 種風格在動。★ 九格都有畫面、都在動嗎？會不會卡？
18. 上面「和現在相近」「對比強的」「3D」「換一批」；點一格＝換成那個風格（Ctrl+Z 可退）；滑過格子右上角「＋ 加進混合」。

## G. 多場景
19. 場景帶右邊「＋ 加場景」→「新的一場」：多一格、舞台換成文字標誌。點第一格切回來：原本的內容、對話都還在。
20. 目前那一格右上「⋯」：改名、複製、往前／往後移、刪除（刪了可以 Ctrl+Z 救回）。
21. 存成檔案再開：所有場景都在。

## H. 聲音（我聽不到，全靠你）
22. ★ 聲音分頁 → 配樂模式（長度 30 秒、形狀任一）→ 聽回落段（最後一段）：和弦和低音還在嗎（以前浩室曲風會只剩鋪底）？
23. ★ 背景執行緒的改動：連續換 3 次曲風，最後那首要等多久才出來？聲音有沒有怪怪的？

## I. 手機（有空再試）
24. 把瀏覽器視窗拉窄到手機寬度（或線上版部署之後用手機開；start.bat 只給這台電腦用，手機連不到）：只有簡潔模式，舞台貼在上面，底部「風格／重抽／導出」。
