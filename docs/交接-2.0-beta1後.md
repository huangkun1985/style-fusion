## 3. 設計上的決定（我定的，使用者可以改）
- 整支片子的配樂用**第 1 場**的音樂設定作一首（每一場一個段落）；其他場景的音樂設定只在「單場」時用。段落種類：1 場＝高潮；2 場＝展開→回落；3 場＝前奏→高潮→回落；4 場以上＝前奏、前半展開、後半高潮、回落。
- 淡轉場：新的一場從 0 秒開始疊上來，上一場在淡入期間繼續播（片子總長不變）。
- 場景帶與時間軸顯示的長度是吸附之後的（和導出一致）。
- 真實音效整個專案共用（依音效種類替換），不是每一場各自一套。關鍵字是寫死的英文對照表（`SFX_QUERY`），**還沒有讓 Agent 依內容建議關鍵字**（提案 3.7 節第 2 點）。
- 真實音效只取試聽檔（Freesound 的 hq MP3），只留第一下、最長 4 秒，存成 22.05 kHz 單聲道 16 位元 WAV；播放時響度對齊它取代的合成音效（`levelMatched`）。
- 全螢幕：兩場以上自動播整支。

## 5. 看到但沒做的
- 時間軸上沒有縮放與捲動：場景很多（12 場、180 秒）時每格會很窄。
- 標記不能拖動（只能刪掉重加）；標記不會跟著場景移動。
- 「音樂遷就畫面」只調速度；拍號、段落種類不能自己選。
- 每一場不能各自選配樂（整支只有一首）。
- 真實音效：沒有音量微調、沒有選片段（只取開頭 4 秒）、Agent 不會建議關鍵字。
- 線上版對外之前的審查項目（R-01、R-06、R-08、R-09、R-22）還沒做（不屬於 β）。
- `sf-themes-v1` 的 8 個上限：整支片子現在不經過這個清單（直接解析各場的 JSON），切換場景時仍會放回清單。
