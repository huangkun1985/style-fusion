## 3. 我定的（使用者可以改）
- 版本叫 `2.0.0-rc.1`（沒人驗收過，不叫正式版）。
- 縮放不存檔；最大每秒 320 像素；Ctrl＋滾輪縮放、一般滾輪只在放大後才攔下來左右捲（沒放大時頁面照常捲）。
- 標記吸到場景交界（6 像素內），Alt 不吸；不吸小節線。
- 標記所在的那一場被刪掉時，用最後存的絕對時間（不會跟著刪）。
- 音量範圍 ±12 dB、0.5 dB 一格；加在響度對齊之後。片段最長 4 秒（和 β 一樣）。原始錄音最多看前 30 秒。
- Agent 建議用「快」的力度、5 組。
- 軟木板顆粒排列變了（重複圖塊 252 像素一輪）；不在 v1 回歸組裡。

## 4. 沒驗證的
見驗收報告第 5 節。最重要：使用者完全沒驗收；所有聲音沒人聽過；看得見的視窗裡的幀率、滾輪與拖動的實際手感沒測（內建瀏覽器面板一直隱藏，`requestAnimationFrame` 和 `ResizeObserver` 都不跑）。

## 5. 看到但沒做的
- 「音樂遷就畫面」只調速度；拍號、段落種類不能自己選；每一場不能各自選配樂。
- 吸附之後總長可以超過 180 秒（12 × 15 秒 → 185.8 秒），只有變紅提示。
- 駭客任務風格每幀 6.5 ms（略超預算）；第一次用到某個後期特效會多花 40～80 ms（編譯著色器）。
- 180 秒片子導出 MP4／風格包的記憶體高峰沒量。
- 線上版對外之前的審查項目（R-01、R-06、R-08、R-09、R-22）。
- `scripts/design-sheet/sheet.ts` 的 regress 組沒有軟木板、波普網點；要把它們加進回歸組得重存基準圖（`?regress=save`）。
