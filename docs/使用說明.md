# Style Fusion 使用說明（2.0）

給**用這個工具做動效提案的人**看的。照「從打開到交出去」的順序寫；每一節開頭一句話說這一步在做什麼。
想知道程式怎麼寫的，看 `HANDOVER.md`；每一版改了什麼，看 `CHANGELOG.md`。

---

## 1. 打開

| 怎麼開 | 什麼時候用 | 能做什麼 |
| --- | --- | --- |
| 雙擊 **`start.bat`** | 平常都用這個 | 全部功能，包括 **Agent（用你這台電腦登入的 Claude）** 與 **真實音效（Freesound）** |
| 雙擊 `dist/index.html` | 沒裝 Node.js、或拿到別台電腦 | 除了 Agent 的「直接生成」與真實音效的搜尋下載，其他都能用（Agent 改成手動模式：複製提示詞、貼回答案） |
| 線上版（之後部署） | 給別人看 | 同單檔版 |

第一次打開會把舊版（1.x）的收藏轉成「我的配方」，原資料保留。頂列左邊是**專案名稱**，旁邊的綠點表示已自動儲存。

## 2. 兩種模式

頂列的「簡潔｜進階」切換，**按鈕位置不會動**。

- **簡潔**（預設）：舞台、一條播放列、場景帶、右邊 Agent。挑風格、生成內容、排場景、導出都夠用。
- **進階**：多了左邊的素材庫（圖像風格、動效風格）、舞台下的「混合配方」、右邊的「調整／聲音／規格」分頁，場景帶換成**完整時間軸**。

手機寬度只有簡潔模式。

## 3. 找風格

**混合**：圖像風格（顏色、筆觸、材質）× 動效風格（節奏、緩動、運鏡），各可同時選最多 6 個並調強度（進階模式左邊）。

**風格牆**：播放列的「風格」。舞台變成 3×3，同一段內容套 9 種風格一起動。
- 上面的篩選：「和現在相近」「對比強的」「3D」「換一批」。
- 點一格＝換成那個風格（Ctrl+Z 可退）；滑過格子右上「＋ 加進混合」＝保留現在的、多混一個。

**靈感骰子**（R 鍵）：全部隨機（主體、風格、參數、音樂），鎖住的不換。

**A／B 比較**：頂列「記下 A」，之後隨便改，按住「按住看 A」就看到原本的，放開回到現在。

## 4. 做內容：Agent

右邊的 Agent 面板。**要 `start.bat` 開、而且這台電腦的 Claude Code 已經登入**（面板上方寫「已連上你的 Claude」）。

1. **選風格模板**（「換一個」）：決定這段動畫的視覺與節奏方向，初始提示詞會自動帶好。
2. **改主題那一行**：寫你要的內容，例如「早晨的咖啡杯，蒸氣慢慢升起」。
3. **生成**：約 40～70 秒（面板有秒數，可以取消；等的時候舞台照常能用）。
4. 結果先**預覽**，還沒套用：按住「比較」看原本的；「套用」或「放棄」。
5. **對話修改**：播到不滿意的地方 →「附上時間點」→ 寫要改什麼 → Enter，約 10～20 秒。修改卡會寫改了什麼、動到哪些時間（點時間跳過去）、每幀耗時。

**內建模板**（文字標誌、UI 介面、數據圖表…）不能用對話改，但可以直接改上面的字（標題、副標、總額…）；打完字離開輸入框，Ctrl+Z 一次退回整段。

連不上 Claude 時，面板自動變成**手動模式**：同一份提示詞「複製」給任何 AI，把回答「貼回」。

## 5. 排一支片子：場景與時間軸

**場景**：場景帶右邊「＋ 加場景」（新的一場、複製這一場）。目前那一格右上「⋯」：改名、長度、複製、往前／往後、刪除（刪了 Ctrl+Z 救回）。最多 12 場、總長 180 秒。

**整支／單場**：場景帶的「整支」從第一場接著播到最後一場；再按一次回到只循環這一場（細調用）。

**完整時間軸**（進階模式）：三列共用同一條時間刻度。

| 列 | 做什麼 |
| --- | --- |
| 上：時間刻度與標記 | 點刻度跳到那個時間。「加標記」在播放頭放一個菱形（例如「口播開始」「Logo 出現」）。**點**菱形跳過去、改名、刪除；**拖**菱形改時間（會吸到場景交界，按住 Alt 不吸）；選到菱形時 ←／→ 微調 0.1 秒（Shift 一次 1 秒）。**標記黏在它所在的那一場**：前面的場景改長度、或整場搬位置，標記跟著走。 |
| 中：場景 | 寬度＝這一場的長度。點一下切過去；**拖右邊緣**改長度；左上「|」按一下變「淡」＝從上一場淡進來。 |
| 下：配樂段落 | 每一場對應的段落（前奏、展開、高潮、回落）與小節數。 |

工具列：
- **畫面遷就音樂**（預設）：每一場吸到整數小節，換場落在小節線上。**音樂遷就畫面**：長度不動、配樂速度微調（最多 ±6%），長度已經和口播或客戶對好時用。
- **淡轉場**：0.2～1.5 秒。
- **縮放**（右邊 −／倍率／＋）：場景多、每格太窄時放大。**Ctrl＋滾輪**以滑鼠位置為中心縮放；放大後滾輪左右捲、底部的細條可以拖；播放時播放頭跑出畫面會自動跟上。點倍率回到「整支放得下」。

## 6. 聲音

進階模式右邊「聲音」分頁（M 鍵開關聲音）。瀏覽器規定要先點一下才能出聲，所以每次打開聲音是關的。

- **配樂**：依風格自動作曲，長度和動畫循環對齊。整支片子時，用**第 1 場**的音樂設定作一首，每一場一個段落。也可以選「名曲」（公共領域）或匯入自己的 MIDI。
- **聲音方案**：8-bit NES、Game Boy、C64 SID、Mega Drive FM、MIDI（真實樂器取樣）、XM。
- **動作音效**：起跳、落地、彈出…在動作發生的那一格自動觸發；「音效包」換一整組聲音。

### 真實音效（要 `start.bat`）

把程式合成的音效換成 Freesound 上的錄音。整個專案共用：換了「落地」，每一場的落地都用它。

1. 「真實音效」區塊裡，每一種用到的音效一列。▶ 試聽現在的。
2. **換成真實**：自動用英文關鍵字搜尋（預設只搜 **CC0**，可以自由使用）。
   - 不知道英文怎麼說：按 **Agent 建議**（要連上 Claude），依這一場的內容想幾組關鍵字，點一下就搜。
   - 清單有長度、下載數、評分（幾人評）、授權、作者、描述。評分看人數：★4.4（380 人）比 ★4.9（6 人）可靠。
   - 每一列左邊 ▶ 試聽 Freesound 的試聽檔；「選這個」會下載、只留第一下、對齊音量，存進專案。
3. **調整**（滑桿圖示）：
   - **片段**：波形上拖兩邊的把手改開頭結尾、拖中間整段搬、點空白處把這段搬過去（最長 4 秒）。「自動選段」回到只留第一下。2.0 正式之後選的音效會重新抓原始錄音，可以選任何一段；更早選的只能從存起來的那段裡再剪短。
   - **音量**：−12～+12 dB，加在「自動對齊合成音效的大小」之後。
   - 「試聽這一段」聽到的就是套用後的聲音；按「套用」才寫進專案（Ctrl+Z 可退）。
4. **還原**（↺）：回到合成的。

授權：CC0 不用標示；BY 要標示作者（風格包的讀我與規格頁自動列出）；BY-NC 不可商用。

## 7. 交出去

**導出**（頂列右上）：

| 格式 | 給誰 |
| --- | --- |
| MP4（含聲音）／WebM／GIF | 看效果的人 |
| PNG 序列、精靈圖、單張 PNG | 要逐格素材的人（可透明背景） |
| WAV／MIDI／XM | 配樂、音效 |
| **風格包**（ZIP） | 客戶與工程師：提案影片、規格.html（段落條、標記表、每一場的畫面、色板、緩動曲線、CSS／GSAP／AE 代碼）、色板檔、代碼檔、分軌或配樂 MIDI、專案檔、讀我 |

有兩場以上時，導出視窗有「範圍：這一場／整支片子」。

**全螢幕展示**（F 鍵）：兩場以上自動播整支。動滑鼠才出現場景名稱與控制；底部細條是進度（直線是場景交界）；**S 鍵**開關規格卡。Esc 離開。

**分享**：
- 「存成專案檔」（`.sfproj`）：所有場景、標記、轉場、長度、真實音效都在裡面。對方在 Style Fusion 用「專案名稱 ▾ → 開啟檔案」打開。
- 配方碼（`SF1.` 開頭）：只有一組風格設定，貼在訊息裡就能分享。

## 8. 存檔與復原

- **自動儲存**在瀏覽器裡（不同瀏覽器、無痕視窗各自分開）。換電腦或備份用「專案名稱 ▾ → 存成檔案」。
- **Ctrl+Z 復原、Ctrl+Shift+Z（或 Ctrl+Y）重做**：拖滑桿、拖時間軸、打一段字都算一步。

## 9. 快捷鍵

| 鍵 | 功能 |
| --- | --- |
| 空白鍵 | 播放／暫停 |
| ← → | 逐格（時間軸上選到標記時：微調標記） |
| Ctrl+Z／Ctrl+Shift+Z | 復原／重做 |
| F | 全螢幕展示 |
| S | 全螢幕時開關規格卡 |
| M | 聲音開關 |
| R | 靈感骰子 |
| O／P／G | 洋蔥皮／運動軌跡／四宮格 |
| Ctrl＋滾輪 | 時間軸縮放（滑鼠在時間軸上時） |
| Esc | 關掉視窗、離開風格牆或全螢幕 |

## 10. 常見問題

- **Agent 寫「手動模式」**：不是用 `start.bat` 開的，或 Claude Code 沒裝、沒登入（在命令提示字元執行 `claude auth login`，再按「重新檢查」）。
- **真實音效不能搜尋**：要用 `start.bat` 開；Freesound 暫時連不上時等一下再試。
- **沒有聲音**：先點一下頁面再開聲音（瀏覽器規定）；音效包設成「關閉」時動作音效不會響。
- **MP4 不能選**：瀏覽器不支援 WebCodecs，改用 WebM 或 GIF（Chrome、Edge 最穩）。
- **時間軸每格太窄**：右上「＋」放大，或 Ctrl＋滾輪。
