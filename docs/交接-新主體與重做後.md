## 2. 工具（新增）

- 接觸表畫自訂主題：`sheet.html?s=custom&theme=<網址編碼的專案路徑>&style=…`
- 檢查主題檔：`npx tsx scripts/design-sheet/check-theme.ts <檔>`
- `sheet.html` 已載入 Google Fonts（之前接觸表的字都是後備字型）
- 冒煙測試 `?all=1` 現在 `window.__n` 應為 **1890**（加了音樂視覺化）
- 音樂視覺化指定曲風：`sheet.html?s=music&genre=<曲風>&seed=<n>`
- 開發伺服器常在換 session／隔一段時間後停掉：navigate 失敗就 `preview_start style-fusion`；PNG 接收器 `recv.mjs`（埠 5555）每次要重開、用完關掉。

## 3. 使用者這次反覆強調的（已記進記憶）

- **動畫要符合主體常理**（光圈不會從四面飛來組合；煙火要在夜空）。主體要自帶它需要的環境，不吃風格的白底。
- **參考圖只學質感與做法，不能拿掉角色自己的辨識特徵**；已認可的 2D 設計就是 3D 版的參考圖。
- 精緻、克制配色、不要廉價／玩具感；建模不能偷懶；要「抄得像」。
- 每次改完都要用接觸表看 1.88:1 每個時間點，至少 flat／popart／cyberpunk／pixel8（線稿類看 chalk），3D 看 matte3d／clay3d／cel3d／wire3d。
