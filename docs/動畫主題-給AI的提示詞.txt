請幫我設計一個 Style Fusion 的「動畫主題檔」（JSON）。

【工作流程（請照順序做）】
步驟 1：規劃。用 3 到 10 行寫出：① 配色表：主角每個部位用哪個色板角色（含明暗）、哪些角色需要在 palette 宣告成特定顏色（圖層裡不准出現 #rrggbb）；② 動作時間表：這個動畫一個循環（loop 秒）裡有哪些動作、各自在哪個 u（0–1）、要用哪些圖層與關鍵影格、哪個瞬間要配什麼音效與理由。
步驟 2：寫 JSON。嚴格遵守下面的格式。
步驟 3：自我檢查（不用輸出檢查過程，只要確保都符合）：
  □ 每條關鍵影格 u 從 0 到 1，結尾的值等於開頭的值（旋轉差 360 的倍數），可以無縫循環
  □ 音效的 u 都取自動作的關鍵影格時間；音效種類符合動作與主角（見音效規則），沒有 step 用在非走路上
  □ 只有「站在地面上」的東西才寫 ground；水面、空中、太空、漂浮的主角不要寫 ground（會畫出一塊地板）
  □ w 只對 rect（寬度）、line／curve／arc（線寬）有作用；圓、橢圓、多邊形的描邊粗細用 lw
  □ 搜尋整份 JSON 的「#」：只能出現在 palette 的值裡；圖層的 fill、stroke 全部是色板角色（可加明暗如 a-8、a+25），使用者才能在「自訂色板」改色（見顏色指南）
  □ 每個 id 不重複；shadowFor、track 指向存在的圖層；圖層由後往前排列
輸出：先寫步驟 1 的時間表，然後把完整 JSON 放在「最後一個」```json 程式碼區塊裡（JSON 不能有註解，區塊外不要再有 JSON）。

【設計要求】
- 圖形用簡單的幾何圖層（圓、橢圓、圓角矩形、多邊形、曲線、文字）拼出來，原創設計，不要模仿現成的角色或作品。
- 善用 children（巢狀）做肢體與關節、delay 做尾巴與天線的跟隨、react 讓動效風格的「誇張」「果凍」影響動作幅度。
- 子圖層的座標是相對於父圖層；主角用一個 group 包起來，整體的起伏與傾斜寫在這個 group 上，細節動作寫在子圖層。
- 動作要有次要動作與預備：落地前身體先拉長、落地後擠壓、再回彈；頭、尾巴、翅膀不要和身體同時動，用 delay 錯開。

【Style Fusion 動畫主題檔格式（版本 1）】
純 JSON，沒有程式碼。座標：畫面中央是 (0,0)，x 向右、y 向下，短邊固定 400 單位（所以上下大約 −200 到 +200）。

最外層：
- format（必填）："style-fusion-theme"；version（必填）：1
- name：名稱（≤40 字）；desc：一句話說明
- loop：一次循環幾秒（0.5–30，預設 3）；hero：靜態縮圖用的時間（0–1）；key：最有代表性的時刻（0–1，子彈時間的中心）
- ground：地面的 y（選填；有的話會畫地面，風格自帶地面的背景會略過）；shadowFor：要在地面投影的圖層 id；shadowSize：影子大小
- track：軌跡線／速度線追蹤的圖層 id（預設第一個圖層）
- events：事件陣列，每個 { "u": 0–1, "x": 數字, "y": 數字, "k": 強度 0–1.5, "sfx": 音效名 }。事件處會有衝擊特效，sfx 會在那一刻觸發動畫音效（jump、land、bounce、pop、click、toggle、whoosh、tick、ping、sparkle、impact、step、notify、rise、drop、flip、blip、splash、quack）
- sounds：只出聲、不產生衝擊特效的音效點陣列，每個 { "u": 0–1, "sfx": 音效名（同上，必填）, "k": 強度 0–1.5 }。想讓動畫有動作音效就用 events 的 sfx（要配衝擊特效）或 sounds（純音效）；兩個都沒寫就是無聲
- layers（必填）：圖層陣列，由後往前畫

圖層：
- type（必填）：group（只當容器）、circle（r）、ellipse（rx, ry）、rect（w, h, radius）、polygon／blob（points：[x1,y1,x2,y2,…]，至少 3 個點）、line／curve（points，至少 2 個點；w 線寬）、arc（r, a0, a1 角度；w 線寬）、text（text, size, align, font）
- id：名稱（選填，要被 shadowFor／track 參照時才需要，不能重複）
- 顏色 fill／stroke：色板角色 bg、bg2、ink、light、card、p、s、a、q、r（會跟著圖像風格換色、使用者也能在「自訂色板」改色），可加明暗：a+20＝比點綴色亮 20%、a-15＝暗 15%（明暗範圍 1–99）；圖層的 fill／stroke 不要寫 #rrggbb（寫死的顏色使用者無法在「自訂色板」改，也不跟圖像風格換色），要特定顏色就用 palette 宣告；fill 設 null＝只描邊；stroke 設 false＝不描邊
- palette：主題自帶的色板，{ "a": "#FFD43B", "r": "#FF9F1C" }（角色 → #rrggbb）。這些角色固定用你指定的顏色（不跟圖像風格換），使用者仍可在「自訂色板」改掉。用來定義主角的身份色，例如黃色鴨子：palette 的 a 設成鴨子黃，身體寫 fill "a"、翅膀 "a-8"、肚皮 "a+25"，嘴與腳用 palette 的 r 加明暗
- 變換（都可以是數字，或關鍵影格陣列）：x、y、rot（度）、sx、sy、s（等比例縮放簡寫）、alpha（0–1）
- opacity：固定的透明度；lw：描邊粗細倍率；react：讓動效風格的「誇張」「果凍」放大這個圖層的動作（0–3）；delay：延遲跟隨（0–1，用於尾巴、天線、頭髮）
- children：子圖層，會跟著父圖層的位移、旋轉、縮放（骨架／巢狀）
- 其他旗標：shadow、hl、glow、flat、outline（true／false）

關鍵影格：[[時間 0–1, 數值, 緩動], …]，緩動是「從這個影格到下一個影格」用的：linear、in、out、inOut（會跟著動效風格的緩動曲線變）、hold（保持到下一格才跳）、back（過衝）、bounce（彈跳）。
為了無縫循環：第一個關鍵影格的時間要是 0、最後一個要是 1，而且最後的值要和第一個一樣（旋轉要差 360 的倍數）。

限制：檔案 ≤200 KB；圖層總數 ≤300、巢狀 ≤8 層；每條關鍵影格 ≤100 個；points ≤400 個數字；text ≤60 字；事件 ≤24 個；音效點 ≤48 個。

【顏色怎麼用（很重要：使用者要能在「自訂色板」改顏色）】
色板有 5 個彩色角色：p 主色、s 輔色、a 點綴、q 自然、r 大地；另有 ink（墨線與文字）、light（高光與白）、card、bg、bg2。
1. 圖層的 fill 與 stroke 一律寫角色（可加明暗），不要寫 #rrggbb。寫死的色碼使用者改不了。
2. 主角需要特定顏色時（鴨子是黃的、番茄是紅的），在最外層用 palette 把「角色」設成那個顏色，圖層再引用該角色。一個色系用一個角色，用加明暗畫出陰影與高光；有兩個色系就用兩個角色，三個以上色系再往 p、s、a、q、r 依序分配。
3. 水、天空、陰影等環境與配角，用其他角色（s、light、ink…），不必寫進 palette，這樣它們會跟著圖像風格換色。
4. 輸出前搜尋整份 JSON 的「#」：只能出現在 palette 的值裡面，圖層裡出現就是錯的，請改成角色。

範例（黃色鴨子）：
"palette": { "a": "#FFD43B", "r": "#FF9F1C" }
身體 "fill": "a"　翅膀 "fill": "a-8"　尾巴 "fill": "a-6"　肚皮 "fill": "a+25"　頭 "fill": "a"
嘴 "fill": "r"　下顎 "fill": "r-8"　腳 "fill": "r"　臉頰 "fill": "r+15"
眼睛 "fill": "ink"　眼睛反光 "fill": "light"　水 "fill": "s"　波紋 "stroke": "light"

【音效怎麼選（音效要「像」動作）】
可用的 19 種音效，括號是實際聽起來的樣子：
- jump 起跳（上揚的滑音）：離開地面、跳起、彈出
- land 落地（低沉的「咚」＋短噪音）：重物著地、踩實、東西放下
- bounce 彈跳（卡通音效包是上揚的彈簧聲，其他是短促的「咚」）：球、果凍、彈性物體
- pop 彈出（短促的「啵」）：氣泡冒出或破掉、物件突然出現或消失、水泡
- click 點擊（極短的乾脆喀聲）：按鈕、卡扣、機關
- toggle 開關（兩聲「答答」，低→高）：切換狀態、扣上
- whoosh 掃過（約 0.5 秒由低到高的氣流聲）：揮動、快速移動、大幅度的翅膀或手臂動作、轉場
- tick 滴答（極短的高音）：時鐘、輕敲、細小的點、水滴
- ping 提示音（清脆的單音鈴聲，帶殘響）：得分、完成、發亮的東西出現
- sparkle 閃光（由低到高的六個鈴音）：魔法、閃耀、星星、驚喜
- impact 撞擊（重低音「砰」＋噪音，約 0.4 秒）：爆炸、重擊、硬碰硬
- step 腳步（短促悶悶的「噗」）：只用在「有腳的角色在地面走路或跑步」。游泳、飛行、划水、滾動、滑行都不要用
- notify 通知（兩個鈴音，低→高）：訊息、提醒、新事物出現
- rise 上升（約 0.55 秒由低到高的掃頻）：充能、升空、膨脹、加速
- drop 下降（約 0.45 秒由高到低的下滑音）：下墜、洩氣、失落、水滴落下
- flip 翻轉（約 0.14 秒的快速噪音掃過）：翻面、翻頁、拍翅、拍水、甩尾、快速抖動
- blip 短嗶（單一音高的短嗶）：只適合電子、像素、機器人、介面類的主題；動物、水、植物等自然物不要用
- splash 水花（約 0.4 秒：入水的「噗」＋水聲＋幾顆小氣泡）：入水、出水、水面被拍打或濺起、潑水、雨滴砸進水裡
- quack 鴨叫（約 0.2 秒沙啞的「呱—克」）：鴨子或類似鴨子的角色叫；只有這一種動物叫聲，其他動物（貓、狗、鳥…）沒有對應，不要拿來代替
沒有其他動物叫聲、人聲、機械運轉聲這類專用音效，要用最接近的代替：拍水＝flip 或 splash（k 小一點），划水＝whoosh（k 小一點）。找不到合適的就不要配。

音效的規則：
1. 先在心裡列出動作時間表：每個明顯的動作瞬間（接觸、轉折、出現、消失）發生在哪個 u。音效的 u 必須取自那個動作的關鍵影格時間（例如盒子在 y 的關鍵影格 0.45 到達最低點，落地音就寫 0.45），不要憑感覺填 0.2、0.5、0.75 這種整齊的數字。匯入時，離所有關鍵影格都超過 0.03 的音效點會被提醒。
2. 寧缺勿濫：每個循環 2 到 5 個音效，平均每秒不超過 2 個。一個動作只配一個音效；規律重複的動作（左右划水）每次配同一種就好。
3. 有接觸表面的瞬間（落地、撞擊、水花濺起）用 events，x、y 放在接觸點；事件同時會畫出衝擊特效。其他動作（揮動、出現、閃爍）用 sounds，只出聲。
4. k 是強度：輕 0.3–0.5、普通 0.6–0.8、重 0.9–1.2。
5. 音色（8-bit、卡通、自然…）是使用者的圖像風格決定的，你只選「種類」。
6. 音效要符合主角的世界觀：自然物（動物、水、植物）用 whoosh、flip、pop、drop、tick、land、splash；機械與電子用 click、toggle、blip、ping、rise；魔法用 sparkle、rise、ping。
