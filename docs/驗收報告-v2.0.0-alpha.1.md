## 2. 內建瀏覽器實測（開發伺服器 5199）

1. 在不執行 App 的同源頁面清掉 IndexedDB 與 `sf-*` 鍵，寫入一份 1.x 格式的 `style-fusion-v1`，**故意放壞欄位**：不存在的風格、`constructor`、權重 9、`aspect: 'banana'`、`speed: 99`、色碼 `#12345`、`view: 'hack'`、`locked` 裡放物件與 `x:evil`、`infoTab: 123`、`scheme: 'toString'`、`bgmVol: 7`、`on: true`，收藏 4 筆（1 筆正常、1 筆欄位全壞、1 筆 `null`、1 筆沒有 id）。

## 3. 沒有驗證的（直說）

- **整體觀感**：只量了座標，沒有看到完整的截圖（面板隱藏）。顏色改成中性灰之後的圖像風格標記好不好認，要你看。
- **雙擊開啟的單檔版（file://）**：內建瀏覽器打不開 file://。IndexedDB 在 Chrome 的 file:// 下通常可用，不能用時會退回 localStorage；沒有實測。
- **真的用滑鼠拖滑桿**：「一次拖曳一步」是用模擬的 pointer 事件測的，沒有真的拖。
- **「按住看 A」用真的滑鼠按住**：用 pointerdown／pointerup 事件測的。
- **手動模式的「複製提示詞 → 貼給 AI → 貼回」**：沒有真的讓 AI 產生一份回答來貼；格式檢查沿用已有測試的 `parseTheme`。
- Safari、Firefox、真手機、無痕模式（退回 localStorage／記憶體的路徑）都沒測。
- 聲音：聽不到；這一版沒有改聲音程式。
- `?full=1`（15,210 次）與 `audio:sweep` 這次沒重跑（沒有動渲染與音訊）。

## 4. 已知限制與設計上的小決定（我自己定的）

- 自訂動畫主題與匯入的 MIDI 仍是整個瀏覽器共用，沒有跟著專案、沒有放進 `.sfproj`。
- 換自訂主題的「內容」不進復原（換主體會）。
- 「開啟檔案」一律開成新專案（新的 id），不會覆蓋同一個專案，避免蓋掉較新的本機修改。
- 「新專案」沿用目前的風格當起點，我的配方從空的開始（配方是每個專案各自的）。
- 簡潔模式的播放列多放了一條時間軸與聲音開關（設計圖沒有畫，但拖時間、開聲音太常用）。
- 「加場景」先是一個說明格（多場景在 α3）。
- 風格模板的選擇沿用「起點選擇器」：替 Agent 選模板時只換風格、不換主體。
- 版面切換的斷點：≥ 1024 才有左右分欄；< 768 只有簡潔模式；768–1023 的進階模式是單欄。
