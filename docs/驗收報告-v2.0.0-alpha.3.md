## 2. 風格牆（實測）
- 打開：9 格（第 1 格「包浩斯 ＋ 瑞士國際主義　目前」），主舞台的 canvas 拿掉（主渲染迴圈不畫）。
- 「和現在相近」（目前是包浩斯）：風格派、新藝術…；「對比強的」：線框、鋼筆線稿、CGA 四色、白模 3D、玻璃擬態…（色板與類別都不同）。
- 換一批：8 格換掉。點一格：換成那個風格、風格牆關掉、**歷史 1 步**，復原回到包浩斯＋瑞士。
- 實際畫面：內建瀏覽器的面板是隱藏的，縮圖排程器靠畫面更新驅動，所以面板裡的 9 格是黑的（**我沒看到真的風格牆在動**）。改用同樣的 9 組規格離線畫一張接觸表：`docs/驗收圖-v2.0.0-alpha.3/wall-all.png`、`wall-contrast.png`（α2 生成的咖啡動畫套 PS1 低多邊形、裝飾藝術、數位雨、毛線、合成波、皮影戲、便利貼、LED 點陣…）。
- 效能：風格牆開著時主舞台不畫；縮圖排程器每幀 7 ms 的預算。**沒有在看得見的視窗裡量幀率**。

## 3. 多場景（實測）
- 新的一場（文字標誌模板、沿用風格）→ 改風格 → 切回第 1 場：生成的咖啡內容（主題 JSON 完全相同）、17 則對話、包浩斯風格都回來 → 再切回第 2 場：像素風格還在。
- 改名「片尾標誌」、往前移、刪除 → 復原：第 2 場回來，而且回到它是目前的場景。
- 長度：3.4 秒＋8.0 秒，總長 11.4 秒。
- 重新整理：兩場都在（生成的那一場帶著主題 JSON）。存成 `.sfproj` 再開：兩場都在（同一份 `currentProject` 資料）。

## 4. 模板的內容欄位（實測）
- 文字標誌 v2：在 Agent 面板輸入「LAUNCH」（逐字打 6 次）→ 離開輸入框 → **歷史 1 步**；復原回到前一個值。
- 換到另一場（生成的內容）：內容欄位是空的（各場各自存）；切回來還是 LAUNCH。
- 畫面：`docs/驗收圖-v2.0.0-alpha.3/content-type.png`（LAUNCH／新品發表，逐字落下回彈照常）。
- 標誌（品牌名）只確認程式改了讀取路徑，**沒有畫接觸表**。

## 5. 匯入的 MIDI 跟著專案（實測）
- 匯入一個 MIDI → 專案資料有 `midi`（2 KB base64）→ 用 App 自己的「清除 MIDI」清掉（場景的音樂變回「關」）→ 開啟剛剛的專案檔：MIDI 放回去、音樂設定回到「匯入的 MIDI」。

## 6. R-14（實測）
- `arrange-test` 新增「回落段（不含最後一小節）要有和弦或低音」：修正前 15 首不合格、修正後 0（1,104 首）。
- 配樂掃描（`SF_ARRANGE=30 npm run audio:sweep midi 3.2`，全部曲風＋名曲）：結束碼 0，最後印「全部正常」（沒有 NaN、削波或音量異常）。
- **沒有聽過**。

## 8. 沒有驗證的（直說）
- 風格牆實際在動的樣子、九格同時播放的幀率（面板隱藏）。
- 場景帶上其他場的縮圖：模板場顯示實際畫面，但會用「目前場景」的模板文字（內容欄位是全域的一份）；生成場顯示名稱卡。
- 拖拉調整場景長度（設計有寫，這版沒做：長度跟著內容與速度走）。
- 標誌的品牌名畫面、很長的標題（超過 8 個字）的排版。
- 聲音與聽感。

## 9. 我自己定的小決定
- 「新的一場」先放文字標誌模板（沿用目前的風格），不放空白：空白舞台沒有東西可以看、也不能套風格牆。
- 風格牆的 8 格以「打開時的混合」為準，按「加進混合」不會在游標底下重排。
- 「3D」篩選本身可以 8 格都是 3D；其他篩選最多 3 格 3D。
- 切換場景時播放頭回到 0。
- 對話紀錄不算一步復原（復原 Agent 的修改時，對話不會被刪）；換場景的復原會把那一場的對話一起帶回來。
