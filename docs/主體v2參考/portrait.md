# 人像插畫（portrait）：參考圖分析與實作紀錄

檔案：`src/engine/subjects/portrait.ts`（新主體；備份 `docs/主體v2重做/2026-10-05/portrait.ts`）

## 使用者的需求（原話）

「我想再增加一個**精細人像插畫**風格的主題，幫我找找美觀的參考圖然後**復刻**。」

## 第三版（2026-10-08，構圖與背景重做、修剪影）

使用者對第二版的回饋：①人臉太中間，排版死板；②幾何色塊當背景很平庸，沒有個性和設計風格，「平面構成能力太弱」，去知名插畫師的網站進修；③「剪影」風格下畫面幾乎全黑。

### 進修（圖檔只在暫存資料夾）

- **Malika Favre**（malikafavre.com 的 Women 作品集，下載 25 張看過）：大膽裁切（人物很大、常被畫框切掉）、偏離中心、視線朝向留白；負空間（臉的亮面和背景融在一起、暗面和頭髮連成一大塊）；背景就是帽簷、頭髮、光影這些「有意義的大形」，不是裝飾色塊；條紋、圓點當節奏；只用 3–4 個顏色。
- **Rokas Aleliunas**（Dribbble，上一輪下載過）：拱門／拱窗框住人物、光影與葉影敘事。
- 只學構圖與光影的方法，沒有照抄任何作品。

### 做法

- **取景**（`frame`）：橫式人物放大（`s = Hu/600`）、偏左（頭在畫面左 0.2 寬）、頭頂被畫框切掉一點，臉朝右邊留白。直式（寬高比 < 0.9）與方形（0.9–1.2）各有自己的縮放與中心。
- **背景＝光與影的敘事**：一面紅牆（`darken(p)`）；拱窗投進來的光在牆上是一塊暖橘的拱形光斑（上亮下暗）；光斑附近的牆有一點漫射亮光；**她的側臉影子落在光裡**（同一組皮膚／頭髮／上衣形狀，縮放後畫在光斑的裁切範圍內，跟著抬頭與呼吸動；光從左邊來，所以影子在右邊）；窗外一枝葉子的影子被風吹得輕輕搖（整枝擺動＋每片葉子各自顫動）。橫式拱窗在右邊留白裡；直式與方形拱窗置中框住頭部，影子只往右偏一點，像一道側臉的回聲。
- **條紋一字領上衣**：紅白條紋沿著領口斜度，隨呼吸起伏——給畫面一個節奏的對比。
- 拿掉第二版所有的有機色塊與奶油色圓點。
- **細節**：影子的裁切範圍比光斑大 3 單位，否則光斑邊緣的反鋸齒會在影子外留下一圈細亮線（看過接觸表才發現、已修）。
- **剪影風格**：該風格的色板除了 `bg`／`bg2`（夕陽）全是墨色；第二版自己畫了一整片由 `p` 調出的底色，結果也是黑的、蓋掉了夕陽。現在 `fill === 'silhouette'` 時牆用 `bg2`、窗光用 `bg`、人物是純墨色剪影，不畫五官、星形妝、耳內（剪影要是一整塊純色）。
- **量化風格**（pixel8）：上半臉的暖色漸層會被量化成灰色，改成不畫。

### 驗證（第三版）

- 1.88:1：`flat` 8 格（u = 0–0.875）＋多輪調整；`silhouette`、`popart`、`cyberpunk`、`pixel8`、`chalk` 各 2 格；直式 9:16、方形 1:1 各 2 格。
- 冒煙測試 1800 次零例外；每幀約 0.8 ms；`npm run typecheck` 通過。

### 還差什麼／沒驗證（第三版）

- 沒在真實舞台播放（葉影搖動、影子跟隨的手感只看過靜態接觸表）；沒聽音效。
- `chalk` 只畫拱窗外框，沒有影子與葉影（線稿風格沒有面）。`popart` 的後期色階會讓窗光的漸層出現一道分界。`cyberpunk` 的後期（泛光、掃描線）會把紅牆提亮成暗棕。
- 光從左邊來，但人物身上的明暗沒有跟著改（臉還是第二版的漸層）；若要更講究，可以在後腦與耳朵加一道窗光的暖色亮邊。

## 第二版（2026-10-08，重做）

使用者看了第一版說「實在太醜了……差成這樣你是在搞抽象嗎」。第一版雖然選了下面這張藍本，但**沒有照著畫**：頭只佔畫面一小塊、臉是一條窄邊、五官簡陋、耳朵比五官搶眼、頭髮是一坨黑、背景色塊比人還大還吵、沒有任何漸層。這次改成**真的復刻**。

### 藍本（Dribbble `tags/portrait_illustration`，圖檔只在暫存資料夾）

黑色鮑伯頭的側臉女孩、眼上一個紅橘色的大星形妝、暖色（橘、紅、珊瑚粉、奶油）有機色塊＋奶油色圓點的背景。這次下載了**原尺寸大圖**（10479×7016），疊上座標格，逐點量出輪廓。只學造型語言、配色與質感，人物是原創插畫（不是真人）。

### 做法

- **座標直接用藍本畫面（1200×803）**：頭髮外形、前額那一綹、露出的一道額頭、側臉線（眉骨、鼻樑、鼻尖、人中、唇峰、上下唇、下巴、下顎底）、脖子前緣、往前的胸口、耳朵位置、星形妝五個尖角，全是在格線圖上量的點。`frame(env)` 依舞台比例縮放：橫式約 0.5 倍（頭約佔畫面一半高），直式（寬高比 < 1.2）改用寬度決定、取景往下移。
- **比例**：頭佔畫面約 49% 高；耳朵在頭髮上、頭髮塞在耳後；髮尾是參差的尖角；脖子長，胸口往右前方伸出。
- **漸層（藍本的質感）**：皮膚由上往下「額頭暖棕 → 脖子淡桃」；下巴在脖子上的楔形投影；鼻翼、唇邊的暖色柔光；耳朵的暖色漸層＋兩層耳內明暗；下唇由紅到淡再帶一點反光。用 `ctx` 直接畫（`lin`、`glow`），只在填色類風格；線稿類不畫。
- **五官**：粗眉（眉頭幾根毛）、半垂的眼瞼、大黑眼珠＋小反光、由細到粗再往上挑的眼線（填色形狀，不是等寬線）、四根往前翹的睫毛、鼻孔一筆、兩色紅唇與唇線。
- **星形妝**：偏斜的五角星（藍本量的位置），每個尖角分亮、暗兩面，像有光照的立體星；臉頰上一顆小星。
- **背景**：珊瑚粉底；上方大橘塊＋裡面的奶油色塊、左上紅塊、頭後斜放的大紅橢圓、紅色重疊處的深紅、左下大橘塊＋奶油色長塊、右下奶油色塊；奶油色圓點與一顆小白點。寬畫面（1.88:1）超出藍本的部分只補一塊右上橘色，其餘留粉底（第一次多補了紅、橘塊，太雜，拿掉了）。
- **配色**：全由 `p`、`a`、`light`、`bg`、`ink` 調出；頭髮用色板中較暗的那個。暗底風格（賽博朋克等）背景色塊往背景色壓得很深，讓人物是主角。**少色數量化風格**（8-bit：`look.post` 有 `quantize`）色票裡沒有膚色、桃色會變灰，皮膚改成接近白色。**線稿風格**（黑板）：五官用 `ink`，星形妝、嘴唇改用 `a` 色粉筆線，背景只留淡淡的圓點線。

### 動態（照真人會有的細微動作，循環 6 秒）

- 呼吸：一圈兩次，胸口與頭微微起伏（胸口比頭多一點）。
- 眨眼兩次（u = 0.22、0.66，各約 0.15 秒），對應音效 `tick`。
- 中段（0.34–0.9）微微抬頭約 2°，眼睛跟著睜大一點、眼珠往上一點；抬頭時一道光由後往前掃過星形妝（0.4，音效 `sparkle`）。
- 皮膚是同一個形狀：頭部的點隨抬頭轉、胸口不轉、脖子漸變過去，所以描邊風格下也沒有接縫。
- 頭髮以頭頂為支點慢半拍；耳環像鐘擺慢半拍擺動；背景色塊緩慢漂移並輕微變形、圓點浮動（全部整數圈數，無縫）。

### 驗證

- 1.88:1 接觸表：`flat` 8 格（u = 0–0.875）＋臉部放大與藍本並排對照；`popart`、`cyberpunk`、`pixel8`、`chalk` 各 2 格；直式 9:16 2 格。
- 冒煙測試 `?all=1`：1800 次、零例外。每幀約 0.7–1.1 ms（`?bench=1`）。`npm run typecheck` 通過。

### 還差什麼／沒驗證

- 沒在真實舞台播放（眨眼、抬頭的手感只看過靜態接觸表）；沒聽音效。
- 直式 9:16 下半部是一大片平塗的胸口，比較空。
- `pixel8` 會把五官量化成幾個像素、粉底變灰（NES 16 色的限制）；`cyberpunk` 的後期（泛光、掃描線）會把背景色塊提亮成暗棕／暗紅。
- 藍本頭髮是純黑沒有光澤，這裡照做；若要更「精細」可再加極淡的髮絲光澤（第一版加過，像塑膠，所以拿掉）。
