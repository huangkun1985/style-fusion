# 文字標誌（type）v2 第二版：參考圖分析與仿照紀錄

日期：2026-10-07　檔案：`src/engine/subjects/v2/type.ts`（備份 `docs/主體v2重做/2026-10-05/type.ts`；第一版在 `docs/主體v2初稿/subjects/type.ts`）

## 參考圖（僅供學習參考，圖檔沒有放進專案）

來源：Dribbble 標籤頁 <https://dribbble.com/tags/kinetic-typography>（作者名未逐一記錄）。下載 20 張做成接觸表挑選，細看 3 張：

1. **BANTER!**（主要藍本）：巨大粗體斜體字，正面奶油色，背後三層擠出（橘紅、粉、深酒紅），像印刷套色錯位；藍底；整張只有 4 個顏色。
2. **GOGOGO**：每個字不同色的圓角粗體字加黑色細描邊與多層擠出（只取「擠出的層次」）。
3. **SH-IFT／MOTION 海報**（Swiss 風）：洋紅色塊、極小的黑字資訊列、細橫線——和巨大標題形成尺度對比。

## 為什麼好看

- **一個字、一個巨大的斜體粗體**，不是六個顏色各異的字。
- **疊層擠出**：正面單色，背後三種顏色各佔三分之一厚度，邊緣銳利；最遠處一層柔影。
- **配色極少**：正面、三層擠出、背景。
- **尺度對比**：標題大到頂天立地，周圍的資訊小字小到 10 單位上下，用細線和等寬字排成「資訊層」。
- **跑馬燈環帶**增加動態與版面的收束。

## 第一版的問題

六個字各用紅藍黃輪流上色（像積木玩具）、只有平的正面和一個模糊投影、旋轉徽章和三個標籤是「模板感」的裝飾、沒有層次的資訊。

## 對應到我們的設計語彙（顏色一律用色板角色）

背景亮度決定配色（`luma(bg) < .55` 為深色）：

| | 深色背景（藍本） | 淺色背景 |
| --- | --- | --- |
| 正面 | `mix(light, p, .06)` 奶油 | `p`（奶油在淺底上會消失） |
| 擠出三層（由近到遠） | `p`、`mix(p, light, .5)`、`darken(mix(p, ink, .55), .04)` | 奶油、`a`、`mix(ink, p, .2)` |
| 最遠柔影 | `mix(bg, ink, .2)` | 同 |
| 小字資訊、跑馬燈 | `ink`；跑馬燈底 `ink`、字 `bg` | 同 |

## 實作重點

- **字體 `grotesk`（Archivo 900）＋斜切 −0.2**：Brush 沒有斜切，新增了 `Brush.skew(kx)`（`brush.ts`，只加一個方法）。
- **擠出 = 同一個字畫很多次**：沿 (1, 0.62) 方向每片偏移 `DEPTH·k/STEPS`（`DEPTH 30`、`STEPS 20`，每片 1.5 單位，小於字的抗鋸齒寬度，不露縫），由遠到近分三色。`detail < .55` 時片數降成 3。擠出厚度隨動畫變化：落下時為 0，**落地瞬間彈到 1.35 倍再回穩**（`land` 鐘形），離場時收回。
- **踩到的坑**：
  - 正面的字帶著風格的模糊陰影，在擠出前面形成灰霧（擠出看起來髒、有鋸齒）；正面與擠出層都要 `shadow: false`。
  - 賽博朋克風格的 `glow` 會讓每一片都發光，二十片疊起來變成一團黃色光團。`Brush.text` 原本無法關掉風格的發光，改成 `glow: false` 可覆寫（`brush.ts` 一行）。
  - 像素字體沒有中文字，副標會退回很小的後備字而糊掉；中文副標一律用粗宋體。
  - 小字（`tiny`）在像素風格下改畫成色條（同 UI 主體的處理）。
- **跑馬燈**：每圈剛好走一個單位（`unit = measure(MARQUEE)`，`wrap`），所以無縫循環。
- 動效模式沿用 v1：波浪（`typeWave`）、打字機（`typeWriter`，游標色用 `p`）、字符解碼（`typeScramble`）。
- 時間結構與 v1 相同（`loop 3.4`、`key`、`hero`、`events`、`cues`、`track`）。

## 驗證（2026-10-07）

- 接觸表與放大單格：`flat`（淺底，奶油→紅字正面）、`popart`（黑邊紅字，很像藍本）、`cyberpunk`（深底發光，擠出變成霓虹層）、`pixel8`；動效 `typewriter`。
- 冒煙測試 `?all=1`：1260 次渲染零例外。`?bench=1`：type v2 每幀 1.9 ms（v1 1.5 ms）。`npm run typecheck` 通過。
- 接觸表工具在小尺寸（480 px 寬）的跑馬燈接縫處偶爾看到字重疊，是工具載入字體的時機造成（前幾格用後備字型量寬度）；放大單格與真實舞台沒有問題。

## 與參考圖還差什麼（誠實版）

- 參考圖的擠出方向和斜度更戲劇化（透視感），我們是固定方向的等距擠出。
- 沒有圓角粗體字（GOGOGO）那種造型字體；字體只能用內建的 14 種。
- 淺色背景下正面是強調色、不是奶油——和藍本的「奶油正面」不一致，但在淺底可讀。
- 沒有測 `watercolor`、直式 9:16、3D 風格。
