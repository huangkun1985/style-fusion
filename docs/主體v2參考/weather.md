# 天氣（weather）：參考圖分析與實作紀錄

日期：2026-10-08　檔案：`src/engine/subjects/weather.ts`（新主體；備份 `docs/主體v2重做/2026-10-05/weather.ts`）

## 第一版被評「像玩具、不夠高級」——診斷

第一版照 Dribbble 的 3D 天氣圖示做：卡通立體雲、橘色太陽球、彩虹條紋、粗體數字、平塗藍天。那是「圖示貼紙」的語言，不是高級產品的語言。

## 第二版（目前）：高級天氣 App 的視覺語言

| 元素 | 做法 |
| --- | --- |
| 天空 | 整個畫面是電影感的垂直漸層，隨天氣變化：晴（深藍→淺地平線）、陰／雷雨（石板灰藍，取「色板中較暗的那個」混，避開亮色的 ink）、放晴（地平線帶 `a` 的暖光） |
| 太陽 | 不是球，是三層柔和光暈（`lighter`），雲量越多越弱 |
| 雲 | 三層景深，每層幾團由 12 朵**壓扁的**柔焦橢圓組成（上方受光、下方陰影）＋一層較暗較平的雲底；雲量超過各團的門檻才出現；水平漂移用整數圈數（無縫）；陰天時頂上一層整片雲幕。第一修正前是一顆顆正圓的棉花球 |
| 雨 | 三層細長斜線：遠的細而慢、近的長而快（9／12／16 圈） |
| 閃電 | 雲層深處的大範圍亮光（在雲後）＋每層雲被從內部照亮＋細的分叉閃電＋整個畫面一亮；一閃、暗一下、再閃 |
| 放晴 | 從太陽放射的光束：只有 4 道、不等距、每道疊三層由寬到窄，邊緣自然淡出，很淡（第一修正前是規則等距的硬邊扇形，像舞台燈） |
| 景深 | 兩層不規則稜線的遠山（4 個不成倍數的頻率疊加；第一修正前是規則正弦，像海浪）＋地面霧 |
| 文字 | 左上：城市、**極細的大字溫度（Outfit 200，`index.html` 的字體連結加了 200／300 字重）**、天氣名稱（300，先淡出舊的再淡入新的）、高低溫；溫度在階段之間滾動 |

**動作**（循環 9 秒）：晴 26° → 雲層聚攏 24° Mostly Cloudy → 轉陰下雨 20° Rain → 雷雨 18° Thunderstorms（兩次閃電）→ 雲層散開、光束穿出 21° Clearing → 晴 26°。

**順帶修正**：接觸表頁面 `scripts/design-sheet/sheet.html` 原本沒有引用 Google Fonts，所有接觸表的文字都是後備字型；已加上與 `index.html` 相同的字體連結（真實應用不受影響）。

## 驗證

1.88:1 接觸表：`flat`（12 格全時間點）、`cyberpunk`、`popart`；冒煙測試 1710 次零例外；每幀 0.5 ms；`npm run typecheck` 通過。

## 還差什麼

- 文字直接畫 canvas（為了用細字重），不跟風格的字體走；像素風下改畫色條。
- 主體自帶天空，不吃風格的背景色。`popart` 的色階分離會把天空與雲切成色帶（風格特性）。
- 雲是柔焦橢圓疊出來的，近看沒有真實雲的細碎邊緣。
- 沒在真實舞台播放、沒聽音效；沒看直式。
