# 3D 角色（char3d）v2：參考圖分析與實作紀錄（第三版在最上面）

## 第三版（目前，2026-10-08）：第二版被評「像尖耳朵的熊、一點審美都沒有」

**診斷**：第二版為了學 toto 的「單一色相」，把 2D 狐貓的身分特徵全拿掉了（雙色臉、蝴蝶形口鼻、臉頰毛邊），只剩圓頭＋尖耳＝熊。**教訓：參考圖是學質感與做法，不能拿掉角色自己的辨識特徵；已有使用者認可的 2D 設計時，那就是最重要的參考圖。**

**做法**（逐項對照 2D 版 `subjects/v2/mascot.ts` 的接觸表）：
- 頭：超橢球（k=2.7）的寬圓角矩形（半寬 1.36、半高 1.0），口鼻微凸，兩頰下側三個往外下方的鋸齒毛（`headSurf()`，眼睛、鼻、嘴、腮紅、頭芽也用它算出表面上的位置與法線，貼在表面上）。
- 雙色：**頂點著色**（`twoTone()`：以白色建立 → 寫入 color 屬性 → 開 `vertexColors`；低多邊形／紙雕的逐面明暗會乘上去；基本／線框／霓虹／全息材質略過）。`faceMask()`：頭罩下緣＝兩個眼周往上圓起（0.37）、中央尖角缺口（0.1）、兩側往下收；身體的奶油色肚子、尾巴的奶油色尾尖同一套做法。頭 140×104 分段讓交界乾淨。
- 耳朵：圓角三角形擠出（外紅、內粉），外傾 0.36 rad。
- 表情：地面上睜眼（大眼＋兩顆高光，會眨）、閉嘴「w」；空中「^ ^」笑眼＋上緣平、下緣圓的笑嘴＋舌頭（2D 版一樣）。
- 身體：紅色蛋形＋奶油色肚子、紅色短臂＋奶油色圓爪、奶油色腳、紅色大尾巴（越往尾端越粗）＋奶油色尾尖。
- 背景：拿掉第二版和角色同色的攝影棚漸層（紅底配紅狐貓會糊），改回 2D 版的做法：風格背景＋中性白色柔光（強度 0.05＋0.12·亮度）。
- 跳躍只在展示台上（水平 ×0.62、高度 ×0.6），鏡頭 dist 12.8、目標高 2.25，耳朵不出框。
- **手臂穿模修正**（使用者回報「跳躍時手不見了」）：原本跳起時手臂往上舉 ~2.15 rad，爪子舉進了寬大的臉頰裡。改成「爪子目標位置」驅動：肩膀指向爪子、手臂長度跟著變；站著 `PAW_REST (±0.3, 0.56, 0.6)` 在肚子前，跳起 `PAW_UP (±1.24, 0.8, 0.72)` 在兩側前方、臉頰下緣外（和 2D 版一樣，大頭公仔的手本來就舉不過頭）。用頭的超橢球（加頰毛餘量）檢查爪子（半徑 0.22）在整條插值路徑上都在頭外（最小值 1.10，>1＝在外面）；接觸表看了正面全時間點、放大兩格、`turntable` 環繞的側面與背面。

**驗證**：1.88:1 接觸表 `clay3d`（8 格全時間點）、`cel3d`、`plastic3d`、`matte3d`；閃爍探針開／關陰影 0.014／0.013；冒煙測試 1710 次零例外；`npm run typecheck` 通過。

**還差什麼**：`matte3d` 是白色素體（色板特性）；2D 版的深色描邊只有在有描邊的風格（如 `cel3d`）才出現；沒看 `wire3d`、`glass3d`、直式；沒在真實舞台播放。

# （以下是第二版的紀錄）

日期：2026-10-08　檔案：場景 `src/engine/three/scenes/v2/character.ts`、主體 `src/engine/subjects/v2/char3d.ts`（備份 `docs/主體v2重做/2026-10-05/three-scenes/character.ts`、`char3d.ts`）

## 第一版被評「好醜」——診斷

- 臉是拼貼的：強調色的頭上貼奶油色橢球（眼周、口鼻），接縫明顯，像戴面具；臉頰的毛是往外插的圓錐，像刺。
- 眼睛是扁平黑片；腮紅在某些色板變成黃色色塊。
- 周圍七顆彩色小方塊亂飄，雜。
- 跳躍不合常理：跳出展示台、落在台外。
- 角色太小，展示台是平淡的白盤。

## 參考圖（Dribbble `3d-mascot`，圖檔只在暫存資料夾）

**toto（藍色小狗公仔）**：整隻角色只有一個色相，用明暗塑形；點綴只有耳內、舌頭、黑亮的眼鼻、項圈與金牌；臉頰、口鼻、胸口是一束束雕出來的毛（刻紋＋不規則毛邊）；大頭（約身高四成）、口鼻往前凸、結實身體、寬短腳、雙手插腰；背景是同色相的漸層。

## 第二版做法（角色仍是 2D 版的「狐貓＋頭芽」）

- **一個色相**：全身 `p`；耳內 `mix(p, light, .5)`；眼、鼻、嘴近黑（`darken(mix(ink, p, .15), .25)`）＋白色高光；項圈 `darken(p, .4)`＋小牌 `a`；頭芽 `s`（身分標記）。
- **雕刻**：自訂 `sculpted()`（球體逐點變形）＋ `groove()`（繞 y 軸的週期凹槽＝毛束刻紋）＋ `hem()`（越往下毛尖越往下拉＝不規則毛邊）。頭頂略平、臉頰鼓起；口鼻往前凸、下緣是細的鬍子毛邊；胸口淺刻紋；尾巴是沿曲線、越往尾端越粗的管＋一團毛尖。
- **五官貼在表面上**：用橢球近似算出頭表面的 z，眼睛與高光貼著表面（之前陷進臉裡、只剩一條縫）。
- **姿勢**：上臂＋前臂＋肉球，待機時雙手插腰，起跳時張開；閉嘴時鼻下一道微笑，起跳時張嘴吐舌；腳趾三個小隆起。
- **跳躍只在展示台上**（水平幅度乘 0.62、高度乘 0.75），落地揚起淡淡的塵土。拿掉亂飄的彩色小方塊。
- **背景**：主體的 2D 層畫同色相的攝影棚漸層（中間亮、四周暗）＋地面柔光；線框風格保留淺色紙。
- 試過又拿掉的：眉毛（看起來像兩顆痣）、頭頂幾撮毛（像頭上一團皺褶）；毛邊第一次刻太深（像皺皺的布袋）。

## 驗證

1.88:1 接觸表：`clay3d`（全時間點＋放大）、`cel3d`、`matte3d`、`wire3d`；閃爍探針開／關陰影 0.013／0.012（差異來自角色跳動，不是陰影）；冒煙測試 1710 次零例外；`npm run typecheck` 通過。

## 還差什麼

- `matte3d` 色板是單色白，角色變成白色素體公仔（風格特性）。
- `cel3d` 的色階著色會把毛束刻紋變成條紋。
- 毛束是程式刻紋，沒有參考圖那種一撮一撮分明的毛束造型；舌頭在淡色色板下偏白。
- 沒在真實舞台播放、沒聽音效；你的 GPU 上的閃爍沒確認；沒看直式。
