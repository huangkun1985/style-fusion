# 角色跳躍（mascot）v2 第四版：參考圖分析與仿照紀錄

> 第三版使用者評「更好了但還不滿意」。把放大的畫面和哈士奇參考圖的特寫並排後，找出五個具體差距，第四版針對這五點重畫：①頭要有「深色頭罩＋淺色臉到下緣」的色塊結構（第三版是整顆紅頭裡放一塊白臉）；②身體要有分量（大腿弧線、高光、爪子陰影）；③臉頰的毛是輪廓上的缺口，不是往外長的尖刺；④頭要慢半拍、落地壓扁；⑤角色要更大（約畫面五成高）。

> 第二版（藥丸形身體＋香腸尾巴）使用者評「好一點但還不夠好看」，所以第三版重畫：頭大身小、臉頰有毛、蝴蝶形口鼻區、帶色調的描邊、飽和色塊背景。下面「實作重點」以第三版為準。

## 參考圖（僅供學習參考，圖檔沒有放進專案，專案裡的圖形全是程式畫的）

來源：Dribbble 標籤頁 <https://dribbble.com/tags/cute-mascot>（吉祥物插畫，向量平塗＋粗描邊風格；作者名未逐一記錄，圖已下載到暫存資料夾用 Read 看過）

1. **跳躍的哈士奇幼犬**（最接近「角色跳躍」）：騰空、爪子收在胸前、吐舌，腳下一個淺色橢圓影子表示離地高度。
2. **咬著網球奔跑的柴犬**：眨一隻眼；同樣的粗描邊與三階平塗。
3. **獨眼穴居人**（只用來看線條與陰影語彙）。

## 為什麼好看

- **頭身一體的大圓身體**：頭佔全身約三分之二，寬高比約 1.1–1.2:1；不是「圓球加小臉」，臉本身就是主角。
- **粗而均勻的深色描邊**（深藍黑、不是純黑），圓角接合；線寬約佔角色寬度 1.5–2%。這是「貼紙感」的來源。
- **三階平塗**：底色、較深的陰影色（貼著下／右緣的一圈）、較淺的受光區；沒有漸層與模糊陰影。
- **有辨識度的剪影**：尖耳、捲尾、毛髮鋸齒；就算只看黑色剪影也認得出是什麼。
- **臉的處理**：眼睛只是黑色橢圓加一顆白色高光（有時再加一顆小的），沒有眉毛、沒有眼白；臉中間一塊淺色口鼻區；很小的鼻子；開心時嘴張開、舌頭是粉紅色；腮紅是身體色混白的淡粉，不是另一個顏色。
- **配色克制**：主色（橘或灰）＋奶油白＋一點粉，其餘都是同色系的明暗；背景是單一純色，腳下只有一個橢圓影子。
- **肢體極簡**：爪子是小橢圓、有 2–3 條趾線；沒有手臂的細節。

## 第一版（被評「太醜」）的問題，對照後的診斷

沒有描邊（`flat` 風格預設無描邊）、圓球身體沒有輪廓特徵（只有一根觸角）、眼白加黑瞳加眉毛造成「擔心」的表情、肢體細碎、角色佔畫面太小或被切掉、背景是 `ground()` 的綠紫色塊、半透明的模糊陰影讓畫面髒。

## 對應到我們的設計語彙（顏色一律用色板角色）

| 部位 | 顏色 |
| --- | --- |
| 身體底色（陰影階） | `darken(p, 0.14)` |
| 身體受光面 | `p`（左上偏移、縮小，露出右下一圈陰影） |
| 耳朵、尾巴 | `p`；耳內 `mix(p, light, 0.55)` |
| 口鼻區、爪子、腳、尾尖 | `light` |
| 腮紅、舌頭 | `mix(p, light, 0.55)`（舌頭再 `darken`） |
| 眼睛、鼻子、嘴、描邊 | `ink` |
| 頭頂小芽（身分標記，取代第一版的觸角） | `s` |
| 襯景圓盤、落地平台 | `bg2`；小星 `q`、`a`、`light`、圓點 `a` |

細節門檻（`S.look.detail`）：< 0.45 只剩身體、點眼；< 0.5 不做陰影階、耳內、腮紅；< 0.6 省略趾線、眼睛第二顆高光、舌頭。

## 實作重點（第四版）

- **頭的色塊結構**（最大的改動）：先把整個頭輪廓填成淺色（陰影階→受光階）；再用「沿輪廓頭頂弧線＋眼睛高度收口」畫出深色頭罩；最後用兩個淺色眼周圓＋口鼻區蓋回去，只剩額頭中央的 M 形缺口與兩側深色；輪廓線**最後**才畫（`S.blob(輪廓, null, 描邊)`），把所有色塊的邊收乾淨。這樣淺色臉一路到下緣當輪廓，和參考圖一致。
- **輪廓的毛**：頭輪廓用同一個函數 `headAt(t)` 取點，下半部兩側加鋸齒缺口（錐度漸變），臉頰比頭頂寬；頭罩弧線與輪廓用同一個函數，所以邊緣對得上。
- **身體**：比第三版大；弧形高光（不畫大腿的深色線：試過兩次，貼著輪廓像第二條輪廓、拉開後像括號框住肚子，都不好看）；肚子淺色；腳有陰影階與趾線；前爪有陰影階。
- **慢半拍與壓扁**：頭以脖子為支點，轉動取「稍早」的狀態（`follow`），落地時橫向略寬、縱向略扁；耳朵、尾巴、頭芽同樣跟隨。擠壓時橫向放大有上限 1.45（誇張動效如 disney12 下，第四版之前會被壓成一張餅）。
- **嘴**：張開時上緣平、兩端微翹、下緣圓的「笑嘴」，舌頭在下緣有中線；閉嘴是鼻下一小豎加「w」。
- **顏色**：描邊 `mix(ink, p, .22)`；眼睛直接用 `ink`；陰影階 `darken(mix(p, s, .12), .17)`；淺色 `mix(light, p, .06)`，淺色的陰影階偏冷 `darken(mix(cream, s, .14), .035)`；耳內、腮紅 `mix(p, light, .5)`；角色後面的光暈（見下）。全部由色板角色算出。
- **比例**：K = 1.28（角色約佔畫面五成高），跳躍高度乘 0.82（`YS`），頂點仍在畫面內；地面 G = 168。
- 時間結構（`loop`、`key`、`hero`、`events`、`cues`、`track`）沿用 v1。

## 背景光暈（使用者回饋後改過）

第一版圓盤是實心、半徑 200、有色，仿參考圖的「單色背景塊」。使用者指出：這個主體要放進 136 種風格，大圓盤在很多風格裡很突兀。改為：**白色（`light`）、半徑 132 起由外到內四層漸強的柔邊光暈，沒有硬邊；強度依背景亮度 `0.03 + 0.1·luma(bg)`**（亮底稍明顯、暗底只剩一點點）。有色的半透明圓盤試過，在普普風黃底上混出髒橄欖色，所以改用白色。腳下影子改成中性的 `ink` 半透明，不再帶色相。外圈同心圓與落地平台拿掉。教訓：**主體的背景襯景要中性、柔和、跟著背景亮度走**；參考圖的飽和背景是插畫作品的背景，不是主體本身。

## 驗證（2026-10-06）

- 接觸表：`flat`、`popart`、`pixel8`、`watercolor`（加 `jelly` 動效）、`disney12` 動效六格都看過（放大單格與多格）。像素風只剩粗略輪廓，但「^ ^」眼與吐舌仍清楚；低細節風格會省略背景圓盤。
- 冒煙測試 `?all=1`：1260 次渲染零例外。`?bench=1`：mascot v2 每幀 0.8 ms（v1 0.5 ms）。`npm run typecheck` 通過。

## 與參考圖還差什麼（誠實版）

- 參考圖的輪廓線有**粗細變化**與手繪的收筆；我們的描邊是均勻線寬（Brush 沒有可變線寬）。
- 參考圖的毛髮更細緻、頭頂有一小撮翹毛；我們的尾巴只有底色。
- 我們的角色是原創的「狐貓＋頭芽」，不是任何參考圖的複製。
- 沒有檢查直式（9:16）的收合；沒有測其他圖像風格如長陰影、新擬態（身體已關掉模糊陰影，在那些風格裡不會有陰影）。
