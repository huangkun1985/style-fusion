# 抽象流動（abstract）v2 第三版：參考圖分析與實作紀錄

日期：2026-10-07　檔案：`src/engine/subjects/v2/abstract.ts`（備份 `docs/主體v2重做/2026-10-05/abstract.ts`；第二版的紀錄在 `其餘主題.md`）

## 第二版被評「越看越醜、完全不絲滑、像 20 年前的 Flash，要現代、絲滑、流光溢彩」——診斷

- 平塗的紙片緞帶：硬邊、單色色塊、扭轉處是尖角折痕——正是向量補間動畫的質感。
- 沒有光：沒有發光、沒有透明疊加、色彩不在形體上流動。
- 背景是兩個硬邊同心圓，加上散落的黃點與十字。
- 運動是正弦波平移；再加上我上一輪加的「時間扭曲」（一圈裡忽快忽慢），反而更機械。

## 參考圖（Dribbble `fluid-gradient`，圖檔只在暫存資料夾）

1. **虹彩絲帶**（TEXAS POKER 視覺）：形體由上百條細線組成，扭轉處細線聚攏自然變亮；顏色沿形體流動（青→粉→黃→紅）；深色底。
2. **顆粒漸層**（GRAINY）：深色底上兩三團巨大的柔焦色光＋細顆粒，沒有任何硬邊。

## 第三版做法

- **絲帶**：一條在空間中扭轉的帶子（中心線＝兩個諧波；扭轉角＝螺旋＋慢擺），取 76 條緯線畫成 0.9 單位的細線，`globalCompositeOperation = 'lighter'`——扭到側面時線條擠在一起、亮度自然疊高，就是絲綢的高光。兩端收細（`sin^0.7`）。
- **色彩**：畫面空間的線性漸層 `p → a → s → p`，色帶隨時間緩慢平移，色彩「流過」形體。
- **流光**：一段亮光沿絲帶長度方向流過（每圈兩次）。
- **景深**：後方一條細而淡的絲帶。
- **背景**：由色板算出的深色底（同煙火：較暗的角色＋`s` 的色相、壓到亮度 ≤0.09）＋三團緩慢漂移的柔焦色光（徑向漸層）＋一張固定雜訊圖用 `overlay` 疊上的細顆粒。
- **運動**：全部是 u 的整數週期函數，拿掉時間扭曲——等速、無縫。
- 細線直接畫 canvas（座標用 `S.tp`），效能：每幀 2.9 ms（第一版 92 條×90 點時 5.9 ms，減到 76×64 後外觀相同）。

## 驗證

1.88:1 接觸表：`flat`（全時間點）、`cyberpunk`、`popart`；放大單格確認細線本身乾淨（縮小的接觸表上看到的網格是摩爾紋）；冒煙測試 1620 次零例外；`npm run typecheck` 通過。

## 還差什麼

- 「絲滑」是用連續的週期函數保證的，**沒有在真實舞台播放確認手感**；動效風格若有降幀（例如 12 fps 定格），仍會一格一格跳——那是動效風格本身。
- 主體自帶深色底，不吃風格的背景色（發光要在暗底上才成立）。
- 接觸表縮圖上細線會有摩爾紋；在小縮圖（風格庫卡片）裡可能看起來有網格感。
- 沒看 `pixel8`、`watercolor`、直式。
