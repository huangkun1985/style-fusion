## 為什麼好看

- **風格化比例**：頭小、腿很長、上衣是一大塊有份量的輪廓；不是火柴人，也不是等寬粗線。
- **褲子是錐形色塊**：大腿寬、腳踝窄，外側一條縫線，膝蓋處的轉角像布料；有一塊較亮的受光區。
- **鞋子有厚底與細節**（鞋帶斜線、拼色），不是一顆橢圓。
- **色彩分塊**：外套、褲子、鞋三個色塊，各自明暗兩階；整體 3 個色相以內；背景是中性、低對比的色條與柔和的小丘。
- **姿勢挺拔從容**：身體只微微前傾，手臂自然擺動；不是「衝刺」。

## 第一版（v2 初稿）與 v1 的問題

等寬粗線畫的腿像火柴人、頭小帽子大遮住臉、背景是 `ground()` 的綠紫色塊加滿滿的雲與灌木；v1 更糟。**動畫上的硬傷：腳是滑的**（用正弦角度做的 FK，著地的腳速度和地面捲動對不上）。

## 對應到我們的設計語彙（顏色一律用色板角色）

| 部位 | 顏色 |
| --- | --- |
| 夾克 | `p`；陰影階 `darken(p,.14)`、受光階 `lighten(p,.06)`；肩部較亮、腰下較暗（拼色） |
| 褲子、毛帽身 | `mix(ink, s, .34)`（深色中性）；遠側腿再暗一階 |
| 鞋、圍巾、帽球 | `mix(light, p, .05)`（奶油）；鞋底 `ink`；鞋上的拼色 `p` |
| 皮膚 | `mix(mix(light, a, .42), p, .1)` |
| 背包 | `mix(s, ink, .18)` |
| 背景（遠景、中景、地面） | `darken(bg, k)`（只沿背景的色相變暗；一開始用 `mix(bg, ink, k)` 在黃底上變成髒橄欖色，改掉了）；樹冠 `mix(bg, q, .2)` |

## 動畫：腳釘在地上（最重要的改動）

- **雙骨 IK**（大腿 63、小腿 63，膝永遠朝前）：每隻腳在週期內的位置由 `footAt(p)` 決定：著地段（60%）在身體座標系裡**等速後退**，離地段以餘弦緩動向前並在中途抬高；著地時腳尖朝上、腳尖離地前腳跟先抬起、腳尖朝下，離地後擺回腳尖朝上。
- **地面捲動速度 = 著地腳的後退速度**：`D = 4·half·K / STANCE`（一圈地面位移），所有地面特徵與中景以 D 的整數分之一為週期，所以無縫循環。
- **驗證時抓到的誤差**：一開始地面速度沒乘角色的放大倍率 `K`，腳比地面快約 14%（還是在滑）。量測方法：同一隻腳著地期間取三格，腳的白色鞋面像素右緣每格移動 10.5–11 px，地面石子紋理的互相關位移每格 11 px，修正後吻合。
- **髖高是關鍵的幾何**：髖高要約是（腿＋腳）總長的 95%，支撐腿在中段才會幾乎伸直。我先設成 116（總長 135），結果腿永遠是彎的、整個人像蹲著走；改成 128。
- 髖部在雙腳著地時最低、經過時最高（`H0 − bob·cos(4πc)`）；對側擺臂；頭、背包、圍巾、帽球慢半拍（`follow`）；腳跟著地後有短暫的塵土。
- 時間結構與 v1 相同：`loop 2.2`、每圈四步（落腳 0.125／0.375／0.625／0.875）、`key`、`hero`、`events`、`cues`、`track`。
- 動效風格：`exag` 加大步幅、抬腳與髖部起伏；`noodle`（橡皮管）時肢體變成帶描邊的曲線麵條；`rigid`（剪紙）時變成帶鉚釘的剛性線段。

## 驗證（2026-10-07）

- 接觸表（八個姿勢）：看了接觸、經過兩個關鍵姿勢的放大圖；`flat`、`popart`、`cyberpunk`、`pixel8` 四種風格；橡皮管與剪紙兩種動效。
- 冒煙測試 `?all=1`：1260 次渲染零例外。`?bench=1`：walk v2 每幀 0.4 ms（v1 0.1 ms）。`npm run typecheck` 通過。

## 與參考圖還差什麼（誠實版）

- 參考圖的褲子有細緻的布料皺褶與受光楔形；我們只有一條縫線與一道淡的受光線。
- 參考圖的臉、手更精緻；我們的臉很小很簡化，手只是一個圓。
- 沒有參考圖那種噪點質感（遛狗那張）。
- 剪紙（`rigid`）模式下近側手臂和夾克同色而幾乎看不見。
- 沒有測 `watercolor`、直式 9:16、3D 風格、其他動效風格。
- 角色是原創的「戴毛帽、背背包、圍圍巾」，不是參考圖的複製；好不好看由使用者判斷。
