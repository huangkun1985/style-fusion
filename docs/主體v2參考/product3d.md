# 3D 產品展示（product3d）：參考圖分析與實作紀錄

日期：2026-10-07　檔案：場景 `src/engine/three/scenes/v2/product.ts`、主體 `src/engine/subjects/product3d.ts`、時間表 `src/engine/subjects/productTiming.ts`（備份在 `docs/主體v2重做/2026-10-05/`）

## 參考圖（圖檔只在暫存資料夾，沒有放進專案）

Dribbble 標籤 `earbuds`。主要藍本：**紫色耳機產品海報**（四宮格：開盒在台上、雙耳機懸浮於發光圓台上方）。真實品牌，**學結構與配色邏輯，造型不逐一照抄**。

## 第一版被評「醜、建模偷懶、配色醜、抄也不會抄」——診斷

- 建模：耳機是球＋膠囊、盒子是擠出方塊，和真實產品的曲面差太遠。
- 配色：沒照參考圖的邏輯（參考圖整個畫面一個色相），用了灰台、粉盒、紅環。

## 第二版（目前，依 img2threejs 流程：逐層觀察 → 逐項建模 → 和參考圖並排比對 → 修正）

**觀察到的身分特徵**（參考圖逐層分析）與對應建模：

| 參考圖特徵 | 建模 |
| --- | --- |
| 盒體：寬圓角矩形、底部大圓角（約寬的 15%）、接縫平直、俯視也是圓角 | 自訂「沿圓角矩形放樣」幾何（像車床，但截面是圓角矩形）：底部圓角 → 外壁 → 薄唇邊 → 內壁 → 內底，一個連續殼體 |
| 盒蓋薄、往後開約 105°、內面兩個橢圓凹位 | 同樣放樣（內頂 → 內壁 → 唇邊 → 外壁 → 頂部圓角 → 頂面）；鉸鏈在背面上緣；凹位是略深色的扁橢球 |
| 正面唇邊中央指扣凹槽、接縫下的指示燈、盒內後方銀色磁鐵件 | 深色細長膠囊、自發光小球、銀色膠囊 |
| 耳機頭：蛋形，頭頂外側黑色膠囊出音孔 | 球體依耳塞方向變形拉長成豆子形；出音孔放在頭頂朝前上外側（第一版放在背面看不到） |
| 矽膠耳塞：蘑菇形、外翻邊、中孔，斜裝在頭側 | `LatheGeometry`（外翻邊＋內壁）＋深色中孔 |
| 柄：從頭底部彎出，末端亮銀環＋底蓋小孔，側面感應點 | 沿 `CatmullRomCurve3` 的 `TubeGeometry`＋金屬環＋底蓋＋小孔＋感應點 |
| 展示台：兩層、近黑深紫、下層邊緣亮紫光環 | 兩層圓台（降低環境反射，避免反射成灰色）＋自發光細環＋半透明光暈環＋背後的紫色輪廓光 |
| 整個畫面一個色相（淡紫產品、深紫台、亮紫光、深紫背景、光弧） | 全部由 `p` 推出：產品 `mix(p, light, .3)`、內面 `.18`、耳塞 `.42`；台 `darken(mix(p, ink, .8), .72)`；光 `mix(p, light, .3)`；**背景在主體 2D 層畫 p 的深色徑向漸層＋光弧**（產品照有自己的布景；線框風格例外，保留淺色紙） |

**動作**（照真實產品）：轉盤一圈＝一個循環；轉到正面時蓋子磁吸彈開（ease-out＋8% 過衝）→ 指示燈亮 → 耳機沿槽直直拉出、再往兩側前方移並傾斜展示耳塞、懸浮輕擺 → 吸回 → 蓋子越闔越快、喀一聲 → 燈熄。

**踩到的坑**：放樣幾何的三角面方向寫反，外壁被背面剔除（看得到盒內）；產品顏色太淡＋光強，過曝成白膜；光滑材質的展示台反射環境貼圖變灰；主體檔一度 import 了場景檔與 `materials.ts`，會把 three 拉進主程式包（破壞懶載入）——時間表改放不依賴 three 的 `productTiming.ts`。

## 驗證

- 和參考圖並排比對（開盒在台上、雙耳機懸浮）。
- 1.88:1 接觸表：`plastic3d`、`clay3d`（關鍵幀放大）、`cel3d`（全時間點）、`wire3d`。
- 閃爍：同場景開／關陰影 `__flick` 相同（0.009／0.009），差異來自轉盤旋轉，不是陰影。
- 冒煙測試 1620 次零例外；`npm run typecheck`、`npm run build` 通過。

## 還差什麼（誠實版）

- 參考圖是渲染級的光滑漸層與反射；我們受風格材質與燈光控制，`plastic3d` 下仍偏亮、缺少參考圖那種細膩的高光帶。
- 盒內耳機只露頭部，參考圖的頭更大、填滿盒寬；懸浮時的鏡頭比參考圖遠（參考圖是耳機特寫）。
- 柄是等粗的管，參考圖的柄有微錐度；沒有麥克風網孔紋理。
- 配色跟著風格的 `p`：`plastic3d` 是粉、`clay3d` 是蜜桃色；要和參考圖一樣是紫色，得選 `p` 為紫的風格。
- 沒看 `glass3d`、`chrome`、`neon3d`、直式；沒在真實舞台播放、沒聽音效；你的 GPU 上的閃爍沒確認。
