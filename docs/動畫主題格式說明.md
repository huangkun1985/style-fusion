# 動畫主題檔格式說明（版本 1）

> 讓你自己做一個「主題」（畫面上演的那個東西），匯入 Style Fusion，和內建的角色跳躍、UI 介面等並列。
> 所有**圖像風格**（色板、描邊、填色、後期特效）與**動效風格**（緩動、誇張、果凍、定格…）都會自動套用到你的主題上。
> 檔案是**純 JSON**，不含任何程式碼，只在你的瀏覽器裡處理，不會上傳。

## 1. 三步開始

1. 在舞台下方的主體列最右邊按「**匯入主題**」。
2. 按「載入試試」：範本會立刻變成目前的主題；或按「下載」把範本存下來，用文字編輯器打開改。
3. 改完存檔，按「選擇主題檔…」（或把檔案拖進視窗）匯入。同名的主題會被取代，所以可以反覆「改 → 匯入 → 看」。

範本檔案也在這個資料夾：`範本-動畫主題/範本-彈跳盒子.sfanim.json`、`範本-動畫主題/範本-小行星系統.sfanim.json`。副檔名 `.json` 或 `.sfanim.json` 都可以。

**不想自己寫？** 匯入視窗右邊的「複製給 AI 的提示詞」，貼給 Claude 或其他 AI 助手，最後補一句你想要的動畫（例如「一隻會揮手的小機器人」），就能得到可以直接匯入的檔案。

## 2. 座標與時間

- **座標**：畫面中央是 `(0, 0)`，**x 向右、y 向下**。畫面短邊固定是 400 單位，所以上下大約是 −200 到 +200；橫向寬度依畫面比例而定（16:9 約 −355 到 +355）。要放在畫面裡，圖形的位置大致落在這個範圍內。
- **時間**：一次循環的進度叫 `u`，從 0 到 1。所有「關鍵影格」都用 `u` 來定位，不是秒。一次循環是幾秒由最外層的 `loop` 決定，使用者還可以用「整體速度」「循環長度」微調。
- **角度**：單位是度，正的是順時針（因為 y 向下）。

## 3. 最外層欄位

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `format` | ✔ | 固定寫 `"style-fusion-theme"` |
| `version` | ✔ | 固定寫 `1` |
| `layers` | ✔ | 圖層陣列，**由後往前畫**（陣列最前面的在最底下） |
| `name` |  | 名稱，最多 40 字，會顯示在主體列上 |
| `desc` |  | 一句話說明（最多 200 字） |
| `loop` |  | 一次循環幾秒，0.5 到 30，預設 3 |
| `hero` |  | 靜態縮圖用的時間（0 到 1），挑最能代表這個動畫的那一格，預設 0.1 |
| `key` |  | 最有代表性的時刻（0 到 1）；「子彈時間」類的動效風格以它為中心慢放，預設 0.2 |
| `ground` |  | 地面的 y 座標（−400 到 400）。有寫才會畫地面（風格自帶地面的背景會自動略過） |
| `shadowFor` |  | 要在地面上投影的圖層 `id`（需要有 `ground`）。圖層越高，影子越淡越小 |
| `shadowSize` |  | 影子的大小，預設 40 |
| `track` |  | 軌跡線、速度線等工具要追蹤的圖層 `id`，沒寫就用第一個圖層 |
| `palette` |  | 主題自帶的色板：`{ "a": "#FFD43B", "r": "#FF9F1C" }`（角色 → `#rrggbb`），見「顏色」一節 |
| `events` |  | 事件陣列（衝擊特效，可附音效），見第 7 節 |
| `sounds` |  | 音效點陣列（只出聲、沒有特效），見第 7 節 |

## 4. 圖層

每個圖層是一個物件，**一定要有 `type`**。

### 4.1 圖層類型與形狀參數

| `type` | 形狀參數（括號內是預設值） | 說明 |
| --- | --- | --- |
| `group` | 無 | 只當容器：自己不畫，但它的位移、旋轉、縮放會影響子圖層（做關節、軌道用） |
| `circle` | `r`（20） | 圓，以圖層原點為圓心 |
| `ellipse` | `rx`（30）、`ry`（20） | 橢圓 |
| `rect` | `w`（60）、`h`（40）、`radius`（0） | 矩形，以原點為中心，`radius` 是圓角 |
| `polygon` | `points` | 多邊形，`[x1, y1, x2, y2, …]`，至少 3 個點，自動封閉 |
| `blob` | `points` | 和 polygon 一樣，但邊緣是圓滑的曲線 |
| `line` | `points`、`w`（6） | 折線，至少 2 個點；`w` 是線寬 |
| `curve` | `points`、`w`（6） | 平滑曲線，至少 2 個點 |
| `arc` | `r`（40）、`a0`（0）、`a1`（270）、`w`（6） | 圓弧，從角度 `a0` 到 `a1` |
| `text` | `text`、`size`（40）、`align`、`font` | 文字，`align` 是 `left`／`center`／`right`；`font` 見下表 |

`font` 可用：`sans`、`grotesk`、`round`、`serif`、`mono`、`pixel`、`term`、`display`、`deco`、`neon`、`script`、`cond`、`groovy`。

### 4.2 外觀

| 欄位 | 說明 |
| --- | --- |
| `fill` | 填色。色板角色或 `#rrggbb`。`null` ＝不填色（只描邊）。線條類（line、curve、arc、text）預設 `ink`，其他預設 `p` |
| `stroke` | 描邊色，同上；`false` ＝不描邊；沒寫就由圖像風格決定 |
| `opacity` | 固定透明度（0 到 1） |
| `lw` | 描邊粗細的倍率（0 到 10，預設 1） |
| `shadow`、`hl`、`glow`、`flat`、`outline` | `true`／`false`：陰影、高光、發光、強制平塗、強制描邊。沒寫就由風格決定 |

**顏色請盡量用色板角色**，主題才會跟著圖像風格換色：

| 角色 | 用途 |
| --- | --- |
| `p` | 主色 |
| `s` | 次色 |
| `a` | 強調色 |
| `q`、`r` | 輔助色 |
| `ink` | 墨線、文字的顏色（深色） |
| `light` | 高光、亮色 |
| `card` | 卡片、面板的底色 |
| `bg`、`bg2` | 背景色（拿來「挖洞」或做漸層用） |

介面右側「自訂色板」裡的名稱對應：主色＝`p`、輔色＝`s`、點綴＝`a`、自然＝`q`、大地＝`r`。

**加明暗**：角色後面接 `+數字` 或 `-數字`，就是比該角色亮或暗幾個百分點（1 到 99），例如 `a+25`（比點綴色亮 25%）、`a-8`（暗 8%）。換色板時明暗關係不變，所以一個身體可以只靠一個角色畫出多層次的陰影、高光。

**主題自帶色板 `palette`**：有些顏色是主角的身份（例如黃色鴨子的黃），不該跟著圖像風格亂變。在最外層寫：

```json
"palette": { "a": "#FFD43B", "r": "#FF9F1C" }
```

這些角色就固定用你指定的顏色（蓋過圖像風格的色板），其餘角色照舊跟著風格走。圖層裡用 `"fill": "a"`（身體）、`"a-8"`（翅膀）、`"r"`（嘴）引用。**使用者仍可在「自訂色板」改掉這些角色**，整隻鴨子的所有明暗會一起換色。若直接把顏色寫死成 `#rrggbb`，使用者就改不了。


### 4.3 動起來：變換屬性

這些屬性**可以是一個數字（固定值），也可以是關鍵影格陣列**：

| 屬性 | 預設 | 說明 |
| --- | --- | --- |
| `x`、`y` | 0 | 位移（相對於父圖層） |
| `rot` | 0 | 旋轉（度），繞著圖層原點 |
| `sx`、`sy` | 1 | 水平、垂直縮放（擠壓與拉伸用） |
| `s` | — | 等比例縮放的簡寫（`sx`、`sy` 沒有另外寫時才生效） |
| `alpha` | 1 | 透明度（0 到 1），會連子圖層一起 |

### 4.4 巢狀、延遲與動效連動

| 欄位 | 說明 |
| --- | --- |
| `children` | 子圖層陣列。子圖層的座標以父圖層的原點為準，並跟著父圖層位移、旋轉、縮放。用來做手腳關節、環繞的軌道 |
| `delay` | 延遲跟隨（0 到 1）：這個圖層的動作比設定的晚一點發生，做尾巴、天線、頭髮的「跟隨與重疊」。動效風格的「跟隨」參數會再放大這個延遲 |
| `react` | 讓動效風格的「誇張」與「果凍」放大這個圖層的動作幅度（0 到 3；0＝完全不受影響，1＝完全跟著）。想讓使用者疊上「誇張」風格後動作變大，就設 1 |
| `id` | 名稱（最多 40 字，不能重複）。只有被 `shadowFor`、`track` 參照時才需要 |

## 5. 關鍵影格與緩動

```json
"y": [[0, -110, "in"], [0.45, 80, "linear"], [0.9, -110, "inOut"], [1, -110]]
```

每個關鍵影格是 `[時間, 數值, 緩動]`，緩動可省略（預設 `linear`）。**緩動是「從這個影格到下一個影格」那一段用的**。

| 緩動 | 效果 |
| --- | --- |
| `linear` | 等速 |
| `in` | 加速離開（像落下） |
| `out` | 減速進入（像煞車、像向上拋到頂） |
| `inOut` | 兩端慢、中間快 |
| `hold` | 停在這個值，到下一個影格才瞬間跳過去（定格、開關） |
| `back` | 超過終點再回彈（過衝） |
| `bounce` | 像球落地般彈跳到終點 |

**`in`、`out`、`inOut` 會跟著使用者選的動效風格改變曲線**（例如「彈簧」風格會讓它們帶回彈），所以主題疊上不同的動效風格會有不同的「性格」；想要固定不變的曲線，用 `linear`、`back`、`bounce`、`hold`。

### 無縫循環的要訣

- **第一個影格的時間要是 0，最後一個要是 1**，而且**最後的值要和第一個一樣**（旋轉要差 360 的倍數：例如從 0 轉到 360 或 720 都是無縫的）。
- 沒寫到 0 或 1 時會自動補上，並給你一個提醒；頭尾值不同也會提醒（循環接縫會跳一下）。這些提醒不影響播放。
- 想讓某段時間「不動」，就放兩個相同值的影格：`[0.2, 50], [0.8, 50]`。

## 6. 範本逐段說明

**彈跳盒子**（`範本-彈跳盒子.sfanim.json`）示範：
- `ground`＋`shadowFor`：地面與隨高度變化的影子。
- `box` 的 `y`：`in` 落下 → 落地後下沉一點（擠壓時中心要下移，盒子的底邊才會貼著地面）→ `inOut` 彈起。
- `sx`、`sy`：落地擠壓（扁、寬）與空中拉伸（窄、高），兩者互補。
- `children`：眼睛（眨眼是 `sy` 瞬間變小再回來）、嘴巴（`curve`）、天線（`group` 加上 `delay`，落地後甩動，頂端有顆小圓球）。
- `events`：在 `u = 0.45`（落地那一刻）放一個事件：畫面上有衝擊特效，並觸發 `land` 音效。
- `react: 1`：疊上「誇張」動效風格後，動作幅度會跟著放大。

**小行星系統**（`範本-小行星系統.sfanim.json`）示範：
- 巢狀旋轉：`arm1`（`group`）旋轉 0 → 360，裡面的 `planet` 放在 `x: 130`，所以行星繞著中心轉；`planet` 裡再放 `arm2`（轉 1080 度）和 `moon`，月亮繞著行星轉。
- `fill: null` ＋ `stroke`：只有輪廓的圓環。
- `s`：恆星的脈動（等比例縮放）。
- `text`：文字圖層，`react: 1` 讓它也能被動效風格影響。
- `track: "planet"`：軌跡線追蹤行星。

## 7. 事件與音效

```json
"events": [{ "u": 0.45, "x": 0, "y": 122, "k": 0.8, "sfx": "land" }]
```

| 欄位 | 說明 |
| --- | --- |
| `u` | 發生在循環的哪個時刻（0 到 1） |
| `x`、`y` | 發生的位置（衝擊特效的位置） |
| `k` | 強度（0 到 1.5，預設 0.6） |
| `sfx` | 選填。那一刻觸發的動畫音效（聲音開啟、音效包不是「關閉」時才會響）：`jump`、`land`、`bounce`、`pop`、`click`、`toggle`、`whoosh`、`tick`、`ping`、`sparkle`、`impact`、`step`、`notify`、`rise`、`drop`、`flip`、`blip`、`splash`、`quack` |

事件也是「子彈時間」「定格停頓」這類動效風格找重點的依據。

### 音效種類怎麼選

可用的 19 種音效以及它們**實際聽起來的樣子**如下。沒有其他動物叫聲、人聲、機械運轉聲這類專用音效，要用最接近的代替（拍水＝`flip` 或 `splash`，划水＝`whoosh`，k 調小）；找不到合適的就不要配。

| `sfx` | 聽起來 | 適合 | 不適合 |
| --- | --- | --- | --- |
| `jump` | 上揚的滑音 | 離地、跳起、彈出 | |
| `land` | 低沉的「咚」＋短噪音 | 重物著地、東西放下 | 輕飄的東西 |
| `bounce` | 卡通包：上揚的彈簧聲；其他：短促的「咚」 | 球、果凍、彈性物體 | |
| `pop` | 短促的「啵」 | 氣泡、水泡、物件突然出現或消失 | |
| `click` | 極短的乾脆喀聲 | 按鈕、卡扣、機關 | |
| `toggle` | 兩聲「答答」（低→高） | 切換狀態、扣上 | |
| `whoosh` | 約 0.5 秒由低到高的氣流聲 | 揮動、快速移動、大幅度的翅膀或手臂、轉場 | 很短的小動作 |
| `tick` | 極短的高音 | 時鐘、輕敲、水滴 | |
| `ping` | 清脆的單音鈴聲，帶殘響 | 得分、完成、發亮的東西出現 | |
| `sparkle` | 由低到高的六個鈴音 | 魔法、閃耀、星星 | 沒有閃光畫面時 |
| `impact` | 重低音「砰」＋噪音，約 0.4 秒 | 爆炸、重擊、硬碰硬 | 輕柔的動作 |
| `step` | 短促悶悶的「噗」 | **有腳的角色在地面走路、跑步** | 游泳、飛行、划水、滾動、滑行 |
| `notify` | 兩個鈴音（低→高） | 訊息、提醒、新事物出現 | |
| `rise` | 約 0.55 秒由低到高的掃頻 | 充能、升空、膨脹、加速 | |
| `drop` | 約 0.45 秒由高到低的下滑音 | 下墜、洩氣、水滴落下 | |
| `flip` | 約 0.14 秒的快速噪音掃過 | 翻面、翻頁、拍翅、拍水、甩尾 | |
| `blip` | 單一音高的短嗶 | 電子、像素、機器人、介面 | 動物、水、植物等自然物 |
| `splash` | 約 0.4 秒：入水的「噗」＋水聲＋幾顆小氣泡 | 入水、出水、水面被拍打或濺起、潑水 | 乾燥的撞擊（用 `impact`、`land`） |
| `quack` | 約 0.2 秒沙啞的「呱—克」 | 鴨子或類似鴨子的角色叫 | 其他動物（沒有對應，不要代替） |

規則（匯入時會自動檢查其中三條，違反會出現提醒）：
1. **音效的 `u` 要取自動作的關鍵影格時間**：盒子在 `y` 的關鍵影格 0.45 到達最低點，落地音就寫 0.45，不要憑感覺填 0.2、0.5、0.75。離所有關鍵影格都超過 0.03 的音效點會被提醒。
2. **寧缺勿濫**：每個循環 2 到 5 個音效，平均每秒不超過 2 個（超過會提醒）。一個動作只配一個音效。
3. 接觸表面的瞬間（落地、撞擊、水花濺起）用 `events`，其他動作用 `sounds`。
4. 音色（8-bit、卡通、自然…）由圖像風格決定，主題檔只選「種類」。
5. 音效要符合主角的世界：自然物用 `whoosh`、`flip`、`pop`、`drop`、`tick`、`land`、`splash`；機械與電子用 `click`、`toggle`、`blip`、`ping`、`rise`；魔法用 `sparkle`、`rise`、`ping`。

### 只出聲的音效點：`sounds`

事件會在 `x`、`y` 畫出衝擊特效。如果只想要聲音（例如揮手的「呼」、閃爍的「叮」），用 `sounds`：

```json
"sounds": [
  { "u": 0, "sfx": "whoosh", "k": 0.5 },
  { "u": 0.5, "sfx": "ping" }
]
```

| 欄位 | 說明 |
| --- | --- |
| `u` | 發生在循環的哪個時刻（0 到 1），預設 0 |
| `sfx` | **必填**。音效名，同上表 |
| `k` | 強度（0 到 1.5，預設 0.6） |

注意：
- 一個音效都沒寫（`events` 沒有 `sfx`、也沒有 `sounds`）的主題是**無聲**的，匯入時會有提醒。
- 音效的音色由「聲音」分頁的音效包決定（自動時依圖像風格、動效風格與主體挑選），主題檔只指定「什麼時候、什麼類型」。
- 音效點隨動畫循環走：換「整體速度」「循環長度」，聲音會跟著對齊；`events` 與 `sounds` 合計最多 24 + 48 個。

### 常見錯誤（匯入時會提醒）

- **主角的顏色寫死成 `#rrggbb`**：寫死的顏色不會被「自訂色板」改動（也不跟圖像風格換色），使用者想換鴨子的顏色就改不了。改用 `palette` 宣告身份色，再用「角色＋明暗」引用（見「顏色」一節）。

- **水面、空中、太空的主角寫了 `ground`**：`ground` 會畫出一塊地板。只有站在地面上的東西才寫。
- **圓、橢圓、多邊形寫了 `w`**：`w` 只有 `rect` 是寬度、`line`／`curve`／`arc` 是線寬；其他圖層的描邊粗細用 `lw`（倍率）。寫了沒作用的欄位或拼錯的欄位名稱，匯入時會列出來。
- **音效時間憑感覺填**、**音效太多**、**種類不符合動作**（例如游泳用 `step`）：見上面「音效種類怎麼選」。

## 8. 限制

| 項目 | 上限 |
| --- | --- |
| 檔案大小 | 200 KB（主題檔通常只有幾 KB） |
| 圖層總數 | 300 |
| 巢狀層數 | 8 |
| 每條關鍵影格 | 100 個 |
| `points` | 400 個數字（200 個點） |
| `text` | 60 字 |
| 事件 | 24 個 |
| 音效點（`sounds`） | 48 個 |
| 已存的主題 | 8 個（存在這個瀏覽器；超過會捨棄最舊的） |
| 數值範圍 | 位移、關鍵影格的值：±5000；半徑、寬高：0 到 2000／4000 |

## 9. 常見錯誤訊息

匯入失敗時，視窗會一次列出所有問題與位置（例如 `layers[2].children[0].fill`），照著改就好：

| 訊息 | 原因 |
| --- | --- |
| 不是有效的 JSON | 少了逗號或括號、多了結尾的逗號、用了單引號、寫了註解（JSON 不能有註解）。可以貼到任何 JSON 檢查工具找位置 |
| 缺少 "format": "style-fusion-theme" | 最外層沒寫 `format` |
| 不認得的顏色 | 顏色不是色板角色也不是 `#rrggbb` |
| 緩動要是 … 其中之一 | 拼錯了緩動名稱 |
| 關鍵影格至少要有 2 個 | 只寫了一個影格；固定值請直接寫數字 |
| 找不到 id 為 … 的圖層 | `shadowFor` 或 `track` 指到不存在的 `id`；要先在圖層裡寫 `"id": "…"` |
| points 要是 … 偶數個 | 座標沒有成對 |

## 10. 版本與相容

`version` 目前只有 `1`。之後如果加欄位，會維持相容：舊的檔案照樣能匯入。主題只會留在你的瀏覽器裡；要分享，就把 `.json` 檔傳給對方，對方自己匯入。

分享**配方碼**或收藏時，如果用了自訂主題，對方的瀏覽器沒有這個主題，會看到「尚未匯入主題」的提示；請把主題檔一起給對方。
