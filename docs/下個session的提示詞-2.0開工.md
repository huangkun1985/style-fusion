### 使用者的習慣（補充 HANDOVER 第 4 章）
- 他靠實際點點看驗收；要講清楚哪些沒驗證。
- 他嫌上一版介面「非常複雜」：預設畫面能少一塊就少一塊，複雜功能收進「進階」。
- 他要「亮眼」的功能；2.0 的主角是 Agent 與風格牆，不是時間軸。
- Agent 的第一步一定是「先選風格模板」，輸入框自動帶好初始提示詞；不是讓使用者從空白開始打字。
- Agent 只改生成的內容，不改內建模板。

### Agent 橋接的實驗結果（α2 會用到；實驗程式已刪，做法記在這裡）
- 這台電腦有 Claude Code 2.1.311，使用者已登入（`claude auth status` 回 `loggedIn: true`）。登入過期時請使用者自己跑 `claude auth login`，不要代為輸入帳密。
- 呼叫方式：`claude -p --output-format stream-json --verbose --include-partial-messages --tools "" --strict-mcp-config --no-session-persistence`，提示詞從標準輸入送進去；思考深度用 `--effort low|medium|high`。
- 串流輸出每行一個 JSON：文字片段是 `type: "stream_event"`、`event.type: "content_block_delta"`、`event.delta.type: "text_delta"`；結束是 `type: "result"`（有 `is_error`、`result`、`duration_ms`、`usage`）。
- **啟動子行程時要把 `CLAUDE*`、`ANTHROPIC*` 開頭的環境變數全部拿掉**，在一個空的暫存資料夾裡執行，不給任何工具。
- 橋接伺服器只聽 `127.0.0.1`、要帶一次性的通行碼（標頭）、檢查來源只能是 localhost；網頁關閉連線就停掉子行程。
- 從指令列送中文要注意編碼：Git Bash 的 `curl -d` 會把中文弄成亂碼；用 Node 的 `fetch` 送 UTF-8。
- 實測：短請求約 4 秒；生成 56 秒（低深度 38 秒），修改 24 秒；都一次通過 `parseTheme`。生成的畫面內容正確但不夠好看（字太小、構圖空），初始提示詞要把構圖與字級寫進風格規格。
- 沒測：從 `start.bat` 啟動、連續多輪修改、十幾個圖層的內容、格式不合格時的自動重問。
