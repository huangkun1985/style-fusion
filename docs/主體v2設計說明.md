# 主體 v2 設計說明

「主體」是舞台上「演的那個東西」（角色、UI、文字、風景…）。v1 是最初的設計，**原樣保留**；v2 是依設計原則重新設計的版本。
舞台上方主體列最右邊有 **v1／v2** 全域切換：切換後所有主體、縮圖、聲音提示點都跟著換；沒有 v2 的主體（自訂主題）不受影響。
圖像風格、動效風格、案例配方、聲音**完全沒有改動**，v2 只是把「畫的東西」換成更好看的設計。

> 這份文件也是「設計參考」的紀錄：每個主體 v2 參考了哪些設計原則、做了哪些決定。參考來源是網路上的設計指南與文章（見最後一節）；
> 我讀的是文字說明，**沒有逐張看作品圖片**，所以這些是「依原則設計」，不是「照某件作品臨摹」。

> **2026-10-09 更新**：這份是第一版的設計說明，已被兩輪重做取代。第二版起每個主體都「先找參考圖、下載看過、逐項對照」，
> 逐主體的參考圖、診斷、做法、缺口改記在 `docs/主體v2參考/<主體>.md`（mascot、ui、walk、type、其餘主題、loader、logo、fireworks、
> product3d、weather、portrait、abstract、char3d、music）；新增的 7 個主體沒有 v1／v2 之分。程式備份在 `docs/主體v2重做/2026-10-05/`。

## 共同的設計決定

1. **時間結構與 v1 相同**：循環秒數、事件點、音效提示點（`cues`）、`track`（軌跡）都沿用，所以 68 種動效風格、音樂與音效對齊、導出都不受影響；3D 主體的跳躍姿態也共用 `mascotPose`。
2. **所有顏色都取自色板角色**（p、s、a、q、r、ink、light、card、bg、bg2），所以 136 種圖像風格照樣能換色、換質感。
3. **主體放大、主角佔畫面約 40–50%**（v1 的角色只佔約三分之一），並在背後加襯景（大圓盤、漂浮小圖形、刻度環…）讓畫面有層次。
4. **次要動作與細節只加在「detail」夠高時**：低細節風格（像素、1-bit）會自動略過光斑、塵土、小字等，不會變雜。
5. 全部寫成可無縫循環（位置由 `u` 的週期函數算出，沒有累積狀態）。

## 逐項設計

| **角色跳躍**（跳跳豆） | 豆形身體（下寬上窄，有重量感）、大眼睛加高光、眉毛隨動作變表情（騰空上揚、落地壓低）、肚皮與腮紅、發光觸角；落地揚起塵土與衝擊環，騰空有星屑；背後大圓盤與漂浮小圖形。 | 吸引力（Appeal）：圓形語彙代表友善、大眼睛、明確的剪影；擠壓與拉伸保持體積、預備動作 |
| **彈跳球** | 整條彈跳軌跡用小圓點標出（像動畫師的間距圖，已走過的淡化）；三色風車紋的球會隨位移滾動；下落拖出殘影、觸地濺起水花與衝擊環；固定在左上的高光。 | 擠壓與拉伸、間距（spacing）、弧線 |

## 驗證

- 每個主體都用接觸表（同一主體在多個時間點的畫面）逐張檢查過；3D 主體用實際的 WebGL 渲染。
- 冒煙測試：14 個主體 × v1／v2 × 15 種圖像風格（含平面、波普、像素、水彩、便利貼、文字拼貼、八種 3D 材質）× 3 個時間點，共 1260 次渲染，**沒有任何例外**。
- 效能（640×360、平面風格，每幀毫秒；v1 → v2）：角色 0.4 → 0.5、彈跳球 0.2 → 0.6、走路 0.3 → 0.7、UI 1.0 → 0.9、文字 1.7 → 5.9、幾何 0.3 → 0.5、圖表 0.8 → 1.0、風景 0.8 → 2.8、抽象 1.4 → 3.0。都在一幀預算內；文字 v2 最重（旋轉徽章逐字繪製）。
- `npm run test:audio`（含音訊、匯入 MIDI、自訂主題）全過。

## 沒驗證的部分

- **審美本身**：「頂級設計」是主觀的。我依原則與自己看到的接觸表判斷，但最終好不好看要靠你的眼睛——不喜歡的主體，用 v1／v2 開關比較，告訴我哪個、哪裡不好，我再調整。
- 沒有在每個主體 × 全部 136 種圖像風格下逐一看過畫面（只用 15 種代表性風格檢查，並用冒煙測試確認不會出錯）。
- 沒有看過參考網站上的實際作品圖片，只讀了文字說明（見上）。
- 配方碼與收藏**不記錄** v1／v2：同一個配方碼在不同版本設定下會看到不同的主體外觀。

## 給開發者

- v2 主體在 `src/engine/subjects/v2/`，3D 場景在 `src/engine/three/scenes/v2/`；登錄在 `src/engine/subjects/v2/index.ts`（沒登錄的沿用 v1）。
- `SUBJECTS[id]` 依全域版本回傳（`src/engine/subjects/index.ts` 的 Proxy）；`setSubjectVersion`／`subjectVersion` 切換與讀取，store 的 `subjectVer` 存檔（預設 v2），切換時會讓縮圖重畫、音效提示點重建。
- v1 的檔案只多了幾個 `export`（`ball.ts` 的軌跡函式與常數），行為沒有改。
- 3D 場景編號多了 `island2`、`shapes2`、`text2`、`character2`、`terrain2`（`three/types.ts` 的 `Scene3DId`），各自有獨立的快取鍵。
