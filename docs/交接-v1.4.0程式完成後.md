## 2. 做了什麼

### 1.2.1 修正
- 兩欄版面（1024–1279 px）舞台被壓成 0 高：`App.tsx` 加 `shrink-0`。
- 手機版自動往下捲：`StyleBrowser.tsx` 只捲分類列。
- 音樂視覺化效能：`music.ts` 用二分搜尋的時間窗＋每圈預算；K-Pop 8.2 → 3.5 ms，和音符數無關；與舊版 60 格逐像素相同。
- 導出：音樂視覺化只在即時舞台補償喇叭延遲（`FrameSpec.live`、`liveSong.ts`）；導出視窗「長度」新增「整首」（`exporter.ts` 的 `seconds`）。
- 彈出視窗開著時快捷鍵不作用；配方碼與本機存檔消毒（新檔 `src/store/sanitize.ts`，`Object.hasOwn`）；`PCFShadowMap`；地形 `toNonIndexed` 警告；內嵌 favicon；file:// 不顯示分享連結；「填滿」比例變動重算音效點（store 的 `fitAr`）；本機儲存寫滿會提示；`ctx.resume()` 2 秒逾時。
- 部署：`engines.node >= 20.19`、`.nvmrc`（22）。
- 工具：`sheet.html?full=1` 擴大冒煙。

### 1.3.0 線上版
- 兩種成品：`npm run build` → `dist/index.html`（單檔，雙擊可開，10.4 MB，行為不變）；**`npm run build:web` → `dist-web/`**（拆檔，首屏約 0.4 MB gzip，取樣按樂器用到才下載，含 `sw.js` 離線快取、manifest、`_headers`）。`vite.config.ts`、`scripts/web/sw.js`。
- 音樂渲染移到 Worker：`src/audio/renderWorker.ts`、`renderClient.ts`、`songTime.ts`；取樣在主執行緒解碼後傳入；與主執行緒逐樣本相同；失敗退回主執行緒。
- WebM 有音軌；MP4 的 Opus 退路已驗證能解碼。
- 視覺回歸：`sheet.html?regress=1`（基準圖 `scripts/design-sheet/baseline/atlas.png`）。
- 直式／方形：`subjects/v2/fit.ts`；角色跳躍縮放、文字標誌改排、標誌顯現直排、數據圖表卡片加長置中並縮放；體素島玻璃材質只畫外殼（`three/blocks.ts` 的 `solid`，v1 不受影響）。

### 1.4.0 編曲級配樂
- 配樂模式：`src/audio/arrange.ts`（段落、進場漸強、回落放慢、終止式）；`compose.ts` 的 `arrange`／`bed`／`polish`；形狀：三段、四段、推進、平穩。只用在自動作曲。
- 墊底（不搶口播）：拿掉主副旋律、鼓只留大鼓與踩鈸、2.5 kHz 讓位。
- 精修（預設開，關掉＝1.2 原版聲音）：力度微調、依力度的起音、逐軌響度對齊＋EQ／壓縮（`gm.ts` 的 `renderPolished`，只在 MIDI 方案）。目標表 `src/audio/mixTargets.ts` 由 `scripts/mix-targets.ts` 產生。量測：各聲部跨歌曲的響度標準差 2～3 dB → 0.1～0.2 dB（`scripts/polish-check.ts`）。
- 分軌導出（ZIP：每聲部 WAV＋MIDI＋讀我）：`files.ts`；加總與混音相關係數 1.0000。
- 介面：「聲音」分頁的「配樂與混音」區塊；配方碼帶新設定；AI／Claude 提示詞帶段落。
- 測試：`scripts/arrange-test.ts`（1,104 首＋渲染）已接進 `test:audio`。
