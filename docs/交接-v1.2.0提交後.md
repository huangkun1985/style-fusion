## 2. 正在進行：部署
- 使用者在 Cloudflare 建立部署（新版畫面是 Workers）。建議走 Pages：頁面底部「Looking to deploy Pages? Get started」→ Import Git repo → `style-fusion`；Production branch `master`、Framework None、Build `npm run build`、Output `dist`、環境變數 `NODE_VERSION=20`。
- 若走 Workers：Build `npm run build`、Deploy `npx wrangler deploy --assets=./dist --name style-fusion --compatibility-date 2025-10-01`。
- **部署後要做**：用內建瀏覽器打開網址，檢查頁面、字體（Google Fonts）、3D（Three.js 懶載入）、聲音取樣（內嵌在約 10.3 MB 的單檔）、開啟耗時；失敗就看使用者給的錯誤訊息。網址是公開的，使用者要私密可教 Cloudflare Zero Trust（由使用者自己設定）。
